### `posts/*.md` 형식

파일명은 `{작성일}_{글번호}_{제목}.md` 형식입니다. 각 파일은 다음 순서로 구성됩니다.

1. 프론트매터(한글 라벨): 글번호 / 제목 / 카테고리 / 작성자 / 작성일 / 조회수 / 좋아요 / 배지 /
   해시태그 / 이미지 개수 / 원문 URL
2. 본문 마크다운 — 원본 HTML의 문단·표·목록·강조·밑줄 등을 최대한 그대로 마크다운으로 변환
3. 본문 내 이미지는 `![이미지N](../images/{글번호}_{순번}.jpg)` 형식으로 로컬 이미지를 참조하며,
   바로 아래에 `> **이미지N 설명**: ...` 형식으로 이미지 내용에 대한 1~2줄 설명이 붙어 있습니다.

## 이미지 수집 방식 및 한계 (중요)

본문 이미지는 원본 서버(lxpcms.kbstar.com)에서 직접 다운로드를 시도했으나, 브라우저 자동화
환경의 다음과 같은 제약으로 **원본 파일 그대로 저장하는 것은 기술적으로 불가능**했습니다.

- 스크립트 레벨의 크로스 오리진 `fetch()`가 CORS로 차단됨
- 브라우저의 다운로드 결과 파일이 작업 환경 파일시스템과 공유되지 않음
- 이미지 바이트를 텍스트로 반환하는 경로(base64)는 플랫폼 정책상 차단됨

대신 각 이미지 URL에 직접 접속한 화면을 스크린샷으로 캡처하는 방식을 채택했습니다. 이 방식은
내용 판독에는 지장이 없으나 다음과 같은 차이가 있습니다.

- 스크린샷은 JPEG로 재인코딩되며, 원본이 PNG/GIF인 경우 화질이 손실됩니다.
- 캡처 폭이 최대 약 1,490~1,570px로 제한되어, 원본이 이보다 큰 경우 축소된 상태로 저장됩니다.
- 움직이는 GIF 이미지는 정지 프레임 1장만 캡처됩니다.

이미지 1장당 원본 텍스트 전체를 옮겨적는 대신, 핵심 내용과 주요 수치를 중심으로 1~2줄 설명을
붙였습니다 (처리 속도를 위한 의도적 선택). 이미지 자체(스크린샷 원본)는 `images/` 폴더에 그대로
보존되어 있으므로, 세부 내용이 필요하면 이미지를 직접 열어 확인할 수 있습니다.

`201023_04_BROKEN404.jpg` 1건은 원본 스타런 서버에서 이미지가 삭제되어 404 오류를 반환한
깨진 링크입니다. 원본 이미지는 복구 불가능하며, 해당 사실을 그대로 캡처해 투명하게 기록했습니다.
