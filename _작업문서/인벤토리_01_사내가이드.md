## 핵심 발견

### 1. 자료 계보 (룰의 진화)
- 2021~22: 「수익률 KPI 평가대상」(정기예금 90%↑ / 성과부진펀드 / 수익률 하위 / 고액) → 2022: 디폴트옵션 요건 스코어링(4요건 충족 수로 1~3순위) → 2026: Series1 「고유계정대 50%↑ / 현금성+정기예금 100%」 타겟리스트.
- **타겟팅 룰 정본 = Series1(2026.05) + 51건 신청서(G1~G12)**, 나머지는 패턴·화법 참고.

### 2. 타겟팅 룰 원천 지도
- **오늘의할일 퇴직연금 5종** (임계값 정형): ⑴현금성자산 7,500만↑&非PB ⑵환매추천(성과저조)펀드 보유 ⑶적립금 300만↑&원리금보장100% ⑷적립금 2,500만↑&공격투자형&디폴트 초저위험(불일치) ⑸만기도래 원리금보장 10만↑&적립금 500만↑&디폴트옵션 미등록
- **Series1 Mission**: M1 적립금 1천만↑&고유계정대 50%↑ / M2 적립금 1천만↑&현금성+시중은행 정기예금 100%
- **51건 신청서 그룹 (빈도순)**: G1 만55세×연금저축×IRP 4분면(~20개점) / G2 기업여신 SOHO·법인대표(12) / G3 추가납 여력—잔여한도·900만 미달·전년납입 올해미납(12) / G4 타행 IRP 보유(10) / G9 스타클럽 그랜드↑(8) / G5 DB·DC 가입&개인IRP 미보유(7) / G6 급여이체&IRP 미보유(7) / G8 최근 3년 이탈 재유치(6) / G12 사업자 연납·청약보유(6) / G7 ISA 만기(5) / G10 운용방치—정기예금·고유동성 1천만↑·디폴트미지정·퇴직금 미운용지시(5) / G11 기업형 연계(3)
- **보물지도 18종 룰**: 단말 화면번호까지 명시([04-10-099] 저축종류 55=타행IRP·36=연금저축·83=ISA, [06-12-151] 한도, [04-12-646] 퇴직금 적요 등)
