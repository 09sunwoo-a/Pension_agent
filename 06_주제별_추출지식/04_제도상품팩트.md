# 제도·상품 팩트 — 검증 기준 자료

> 작성 2026-08-17 · 팩트시트 재구성 2026-08-18 · 원천: 01~04 폴더 전체 (행내 가이드 12건 · 스타런 교육자료 · 영업점 Hot Tip · KB Think)

## 이 문서는

01~04 원천 문서에서 **세제·한도·수수료·상품·수익률 등 사실 정보만 전수 추출**해 76개 팩트로 통합한 검증 기준 자료입니다.
용도가 두 가지입니다 — ① **팀이 항목별로 사실 여부를 검토(팩트체킹)하는 리뷰 문서**, ② 검토가 끝나면 각 팩트 문장이 그대로 **에이전트(LLM) 답변의 정오 판정 기준**이 됩니다.

- **원칙: 팩트 1개 = 항목 1개 = 확정값 1개.** 자료 간 수치가 상충하던 12건은 최신·대외공개 자료(KBthink 2025.10~2026.07) 대조로 판정을 끝냈고, **본문에는 확정값만 서술**합니다. 실효된 옛 값은 각 항목의 `이력` 줄로 남겨 추적 가능하게 했습니다.
- 최신 자료로도 판정하지 못한 것은 상태를 `⚠ 확인 필요`로 표시하고 문서 끝 **「확인 필요 목록」**에 모았습니다 — 이 항목들은 해소 전까지 검증 기준으로 쓰지 않습니다.
- **범위**: 당행 개인형IRP 보유 고객의 **사후관리**에 필요한 사실 정보. 신규유치·기업형(DB/DC) 전용은 제외하되 재사용 가치가 있는 것은 `[참고]`로 수록
- **범위 밖**: 고객 선별 기준은 01_고객세그먼트, 판단·제안 규칙은 02_IRP관리방법론, 멘트는 03_영업화법, 화면 조작 절차는 05_업무처리절차 소관

## 항목 읽는 법

각 팩트는 다음 필드로 구성됩니다.

- **팩트** — 값·조건·예외를 담은 자기완결 선언문. **이 문장이 곧 검증 기준문**입니다 (LLM 출력이 이 문장과 모순되면 오답)
- **상태** — `✅ 확정`(검증 기준으로 사용 가능) / `⚠ 확인 필요`(근거 미비·판독불확실 — 해소 전 기준 사용 금지) / `⏳ 시효 민감`(실적·순위·라인업 수치 — 기준시점 병기 없이는 기준으로 쓸 수 없음)
- **성격** — `법령·세제`(법 개정 시에만 변경) / `당행 상품·정책`(정책 변경 시 갱신) / `실적·지표`(분기 단위로 낡음)
- **기준** — 근거 자료의 기준시점
- **대외 안내** — `⭕`(KBthink 등 심의필 있는 대외 공개 문구 → 고객에게 그대로 안내 가능) / `사내`(사내자료만 근거 → 표현을 바꿔 안내, 모집단·시점 병기)
- **조건별 값** — 값이 조건에 따라 갈리는 팩트만. `조건 → 값` 을 `;` 로 이어 적습니다. 팩트 문장에 이미 있는 짝을 **기계가 대조할 수 있게** 옮겨 적는 것이고, 여기 없는 조건을 새로 만들지 않습니다. 에이전트가 "초과인데 16.5%" 같은 잘못된 짝을 잡아내는 근거가 됩니다
- **검증 포인트** — LLM·직원이 자주 틀리는 지점: 실효된 옛 값, 이상/초과, 단위, 지방소득세 포함 여부, 모집단 한정 등. `①②③` 로 나눠 적으면 항목별로 분리돼 대조에 쓰입니다
- **이력** — 상충했던 옛 값과 판정 근거 (덮어쓰기 감사 추적)
- **출처** — 아래 약칭으로 표기. 원문 인용 전문은 git 이력(재구성 이전 버전)에 보존돼 있습니다

## 활용법

1. 아래 **팩트 인덱스**에서 항목을 찾아 제목을 클릭하면 해당 팩트로 이동합니다

3. `✅ 확정` 팩트만 에이전트 검증 기준에 넣습니다. `⏳` 팩트는 기준시점 병기를 조건으로, `⚠` 팩트는 해소 후에만
4. 문서 끝 **「확인 필요 목록」**이 팀·본부 확인 과제, **「이 축에서 제외한 것」**이 제외 추적 기록입니다

### F1. 연간 납입한도 — 1,800만원 (연금저축·DC 개인부담금 합산)

### F2. 세액공제 — 한도 900만원 · 5,500만원 이하 16.5% / 초과 13.2% · 최대 148.5만원

**팩트**: 세액공제 한도는 연간 납입액 **최대 900만원**(연금저축 세액공제 포함)이다. 공제율은 총급여 **5,500만원 이하**(종합소득금액 4,500만원 이하) **16.5%**, **초과 13.2%**(지방소득세 포함)로, 900만원을 채우면 각각 **1,485,000원 / 1,188,000원** 환급된다. 경계 표현은 **"초과"가 정확**하다(5,500만원 정확히 = 16.5% 구간). 단, **세액공제 전 결정세액이 공제액보다 적으면 최대 환급액을 받지 못한다** — 소득이 낮은 고객에게 "900만원 넣으면 무조건 148.5만원"이라고 안내하면 오안내다.

### F44. 연금개시된 연금저축·IRP의 이전 제약 — 건당 0원 계좌 · 이전 후 추가납입 불가

### F57. 증권사 대비 수수료 구조 — 장기할인 승계 비대칭 · '면제' vs '할인'
