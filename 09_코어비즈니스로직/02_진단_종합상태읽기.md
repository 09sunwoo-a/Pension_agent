# 02. 진단·종합 상태읽기

> **v0.1** (2026-08-24) · 세부 단계 구조는 원천 코퍼스(01~05, 08) 전수 훑기에서 귀납 도출.
>
> **질문**: 이 고객의 전체 그림은 무엇인가? · **입력**: 고객 1명의 전체 계좌·이력 · **출력**: 종합 상태 + 검증된 접촉 명분 · **제품**: 개인별 솔루션 화면(브리핑부)
>
> 트리거와 독립적으로 실행 가능해야 한다(인바운드 대응). 트리거 조건만 보지 않고 전체를 읽는다.

## 세부 단계 개요

```
2-1. 가설 검증(오탐 제거)   트리거가 진짜인지 먼저 확인
2-2. 자산 구성 읽기        계좌를 3층으로 분해
2-3. 성과 읽기            격차로 진단
2-4. 납입·세제 현황 읽기    연금 보유 지형 전체 (타사 포함)
2-5. 고객 속성 읽기        성향·생애단계·니즈
2-6. 시계 읽기            만기·기한 타이머
2-7. 상태 플래그·자격 판정  가능한 행동의 제약
2-8. 관계·이력 읽기        접촉·상담·이탈 이력
```

---

## 2-1. 가설 검증 (오탐 제거) — 진단의 첫 작업

- **방치 판정 = 기간 × 사유**: 현금성자산이 ①1개월 이상 금액 변동 없이 유지 & ②입금 사유가 "교체매매"·"연금지급"이 아닐 때만 방치로 확정. 아니면 접촉 보류 [KPI]
- **중복 접촉 확인**: 최근 자동 안내(월간 LMS 등) 발송 이력 확인 — 은행이 이미 한 말을 모르고 접촉하면 신뢰가 깎인다 [KPI]
- 오탐이면 여기서 종료(접촉하지 않음). 오탐 접촉 한 번이 신뢰를 깎는다.

## 2-2. 자산 구성 읽기 — 3층 분해

| 층 | 성격 | 핵심 점검 |
|---|---|---|
| 현금성 | 무선택 대기 | 방치 여부(2-1), 적용 금리 [S1] |
| 원리금보장 | 선택·확정 | 만기, 현 금리 vs 대안 금리 [S1] |
| 실적배당 | 선택·변동 | 수익률, 상품 건강(판매중단·부진 리스트 대조) [KPI] |

- **최대 비중 상품부터**: 금액 비중이 가장 큰 상품의 만기·조건이 대화의 축이 된다 [핫팁:류혜진]
- **편중도 측정**: 층별 비율 (50%/90%/100% 임계) [S1][리마2021]
- **위험자산 한도 점검**: 위험자산 70% 초과 여부 (컴플라이언스 진단 항목) [교육][핫팁:김유리]

## 2-3. 성과 읽기 — 격차 진단

수익률 절대값이 아니라 **기준선과의 거리**로 판정한다. 기준선 4종:

1. 전체 고객 평균 수익률 [S1]
2. 대안 상품 수익률 (지금 옮기면 얻는 것) [S1]
3. 현재 상태 수익률 (그대로면 얻는 것) [S1]
4. **피어 그룹** — 동일 연령대 상위 고객의 운용 현황 [KPI]

- **벤치마크 대조**: 보유 상품 성과를 월 갱신 추천펀드·비교지수(기간별 수익률·변동성·위험등급) 표와 대조 [시황]
- **중도해지 유불리 정량화**: 만기 보유 가치 vs 해지 후 리밸런싱 가치를 계산기로 비교. 복수 예금 매도 순서 규칙(분할인출 적은 것→신규일 최근→금액 적은 순) 존재 [S1][핫팁:원형미]

## 2-4. 납입·세제 현황 읽기 — 연금 보유 지형 (진단의 0단계)

- **전건 기본 조회**: 어떤 용건의 고객이든 연금 보유 지형(당행+타사 연금계좌)부터 연다 — 현장 표준 습관 [핫팁 다수]
- 연간 납입액 / 실제 공제액 / 잔여 한도 (타사 납입분 포함 확장 조회) [핫팁:서영주·김정희]
- 세액공제 미신청금액 존재 여부 (해지·개시 전 필수 확인 항목) [핫팁:김유미·장혜영]
- **"고객이 모르는 자기 현황"**이 최강의 오프너 재료가 된다 — 대다수 고객이 자기 납입·공제액을 모른다 [핫팁:서영주]

## 2-5. 고객 속성 읽기

- **성향 = 행동 이력 기반**: 펀드 운용 경험 전무 → 안전 선호 / 현재·과거 경험 있음 → 분산투자 가능. 조회 범위는 퇴직연금+일반 공모펀드, 폐기계좌 포함 전체 기간 [KPI]
- 공식 성향 분석과 교차 확인 — 나이만으로 안정형 단정 금지 [교육:연령대별]
- **생애단계**: 은퇴까지 잔여기간(연령), 적정 TDF 빈티지(출생연도+은퇴연령)와 보유 상품 대조 [S1][공개]
- **투자가능기간 재산정**: 연금 분할수령 계획이면 기간을 은퇴 시점이 아니라 수령 종료 시점까지로 다시 계산 [교육:연령대별]
- **핵심 니즈 선별**: 내점 사유와 별개로 자산현황·과거 상담이력에서 최대 니즈를 식별 (복수 니즈 중 우선순위) [핫팁:양혜련]
- 이탈 상담 시: 표면 사유(예: ETF) 뒤의 실제 동기(수익률 인식·편의성·테마 선호)를 가른다 [교육:ETF이탈]

## 2-6. 시계 읽기

- 보유 상품 만기 = 자연스러운 재설계 창구. 놓치면 자산이 무선택 대기로 떨어진다 [S1]
- 제도 기한 타이머의 잔여일수: ISA 60일, 과세이연 60일, 디폴트옵션 자동 적용 D-day, 연말 공제 마감 [보물][핫팁]

## 2-7. 상태 플래그·자격 판정 — 상태가 가능한 행동을 결정한다

- **계좌 상태 플래그**: 연금개시 여부, 연금지급설계 등록(추가납 차단), 진행 중 거래(상품변경·자동이체 중), AI일임 운용 중(이전·인출 제한), 실명등록 여부 [핫팁:정소은·오현석][공개]
- **자격 요건**: 연금저축→IRP 이전은 만 55세+가입 5년(예외 있음), 연금개시 요건 충족 여부(추가 개설 가부 판단) [보물][핫팁:진승현]
- **실행 선행조건 예비 점검**: 타행 비밀번호 미등록 등 거절 사유를 상담 전에 확인 (4단계 함정의 사전 제거) [핫팁:김현정]
- 타행 보유상품 실사: 고객 동의하에 함께 조회, 실물이전 가능 상품 목록과 사전 대조 [핫팁:신은지]

## 2-8. 관계·이력 읽기

- 접촉·발송 이력 (최근 6개월 접촉 유무, 자동 안내 수신 여부) [KPI]
- 과거 상담 기록(CRM) — 지난 합의·보류·거절 사유가 이번 진단의 입력 [보물][핫팁:양혜련]
- 이탈·전입 이력 (타사 이탈 완료, 타행 전입 = 재이탈 위험) [타깃51][보물]
- 관리 성공 경험 유무 — 수익률 개선 경험이 있는 고객은 후속 제안 수용률이 높다 [핫팁:최수인]
