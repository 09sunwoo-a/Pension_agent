# 01. 타겟고객 선정

> **v0.1** (2026-08-24) · 세부 단계 구조는 원천 코퍼스(01~05, 08) 전수 훑기에서 귀납 도출.
> 규칙 채우기는 이후 문서별 정독으로 정제한다. 플로우 정의는 [00_전체플로우.md](00_전체플로우.md).
>
> **질문**: 누구에게, 왜, 지금 주의를 쓸 것인가? · **출력**: 우선순위 정렬된 리스트 + "왜 지금" 가설 · **제품**: 대시보드 타겟리스트

## 세부 단계 개요

```
1-1. 입구         어떤 경로로 후보가 되는가
1-2. 트리거 유형   무엇이 신호인가 (5계열)
1-3. 모수·제외 필터 누구를 애초에 빼는가
1-4. 우선순위·정렬  리스트의 순서를 어떻게 정하는가
1-5. 배분·캠페인    누가(어느 채널이) 소화하는가
```

## 1-1. 입구 — 후보가 되는 경로 3종

| 입구 | 설명 | 근거 |
|---|---|---|
| ⓐ 조건식 스캔 | 아웃바운드 — 정량 트리거 조건을 전체 고객에 정기 실행 (본부 타겟리스트·맞춤형 타깃 요청) | [S1][타깃51] |
| ⓑ 이벤트/기한 | 만기·제도 기한·자금 이동 등 시점이 정해진 사건 발생 시 자동 편입 | [오늘][핫팁] |
| ⓒ 인바운드 | 내점·문의 — 리스트와 무관하게 발생. 내점 시 전수 스크리닝이 현장 표준 습관("내점 고객 무조건 세금우대 조회") + 캠페인 대상이면 팝업 알림 | [핫팁:서영주 외][공문] |

## 1-2. 트리거 유형 — 5계열

### T1. 자산 상태형 (구조적 방치·저효율)
- 현금성자산(고유대) 비율 50%↑ / 현금성+일반은행 정기예금 100% — 이탈률 1.3배 실측 근거 [S1]
- 원리금보장상품 100% 운용 [오늘]
- 디폴트옵션 미동의 & 현금성 대기자산 10만원↑ [핫팁:채태정]
- 고액 현금성 대기 (예: 7,500만원↑ 별도 트랙) [오늘]

### T2. 성과형 (상대적 열위·상품 건강 이상)
- 수익률 하위 30% (백분위 + 절대 임계값 병기) [KPI]
- 성과부진·판매중단 펀드 보유 (분기 갱신되는 명시적 리스트 대조) [KPI][오늘]
- 투자성향-운용 불일치 (예: 공격투자형인데 디폴트옵션 초저위험) [오늘]

### T3. 이벤트·기한형 (시점이 정해진 사건)
- **상품 만기**: 사전(D-7영업일, 고액은 D-14) → 경과 후 다단(2일·1주·3주·3개월) [오늘][S1]
- **제도 기한(데드라인 역산)**: ISA 만기 후 60일 / 퇴직금 지급 후 60일(과세이연) / 디폴트옵션 자동 적용(입금 후 2주·만기 후 6주) / 세액공제 실질 마감(11월) [보물][핫팁][공개]
- **생애 이벤트**: 퇴직·희망퇴직·정년 도래, 임원 인사 [교육:IRP사례][공문]
- **자금 이동**: 고액 퇴직금 입금 알림, 일시금 지급 발생 역추적(최근 2개월), ISA 해지금 입금 [핫팁:류수빈·송현진]
- **시즌**: 연초(1~3월) 퇴직금 지급 집중기 [공문]
- **시황 이벤트**: 중요 이벤트(FOMC 등) 전, 영향받는 자산 보유 고객 [시황]

### T4. 행동 신호형 (고객 행동의 변화)
- **이탈 의사 표명**: 계약이전(전출) 신청 접수 = 최우선 즉시 대응 트리거 [보물]
- 납입 중단 신호: 전년 납입 있으나 당해 미납 [교육:IRP사례][타깃51]
- 한도 미소진: 연간 납입액 세액공제 한도 미달 [타깃51]
- 프로세스 중단: 비대면 신규 시도 후 1개월 내 중단 [교육:IRP사례]

### T5. 관리 공백형 (관계의 부재)
- 무권유 비대면 신규·전담직원 미존재 계좌 [보물]
- 장기 미접촉·방치 계좌 [교육:연수교안]
- "자기 현황(납입액·공제액)을 모르는" 미인지 고객 [핫팁:서영주]

## 1-3. 모수·제외 필터

- **관리 가치 하한**: 총 적립금 기준 (예: 1천만원↑) [S1]
- **관할 필터**: 당점/PG 관리 고객으로 한정 [타깃51]
- **채널 소관 제외**: 별도 조직 관리 고객(예: PB센터) 제외 [오늘]
- **제안-상태 부적합 제외**: 연금개시 계좌(추가납 불가), 연금지급설계 등록, 서비스 부적격(AI일임 등) — 제안 유형별 제외 조건 [핫팁][공개]
- **접촉 가능성 필터**: 비대면 마케팅은 개인정보 마케팅 동의 고객 + 동의된 채널만 (하드 룰) [공문]

## 1-4. 우선순위·정렬

- **기한 임박 우선**: 데드라인(60일 타이머 등) 잔여일수 역산 — 지나면 기회 소멸 [보물][핫팁]
- **스코어링**: 복수 요건 충족 개수로 순위 부여 (예: 4요건 중 4개↑=1순위) [공문]
- **다단 정렬**: 편중도(90%↑) → 부진상품 보유 → 상대 수익률 → 고액순 [리마2021]
- **개선 효율**: 적은 개입으로 즉시 개선 가능한 계좌 우선 [핫팁:박서영]
- **용량 제한**: 소화 가능한 수로 캡 (예: 영업점별 최대 200명, 직원별 배분) [리마2021][공문]
- 병용 원칙: '고액순'과 '개선 여력순' 두 정렬을 함께 쓴다 [S1 계열]

## 1-5. 배분·캠페인 운영

- **채널 분담**: 본부 자동 채널(LMS·푸시·배너)이 저강도 전수 커버, 영업점 인적 접촉이 고가치 타깃 담당 [공문][KPI]
- **중복 방지**: 자동 발송 이력과 인적 접촉의 교차 확인 (2-1과 연동) [KPI]
- **기간 한정 캠페인**: 시즌·제도 이벤트에 맞춘 기간제 운영 + 직원별 고객 배분 [공문]
