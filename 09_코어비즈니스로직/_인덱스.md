# 코어 모델 인덱스 — 1차 대조용

> 원천자료 정독 시 **"이미 코어에 있는가"(CLAUDE.md §3-①)를 확인하는 1차 대조 시트**다.
> 이 파일만 읽고 걸리는 항목이 있으면 그때 해당 원본 카드를 펼쳐본다.
> 판단 근거·임계값·예외는 여기 없다. **결정은 항상 원본 문서에서 한다.**

**갱신 규칙**: `01~03`·`10`·`20`에 항목을 신설·삭제하거나 한 줄 요약이 달라지는 개정을 하면
**같은 커밋에서 이 파일도 갱신한다.** 인덱스가 원본과 어긋나면 대조 자체가 무효가 된다.

> 최종 갱신: 2026-08-25 (3라운드 종료 시점)

## 2. 상태·조건 룰 (`10` §2)

| ID | 상태 | 판단 기준 한 줄 |
|---|---|---|
| S-01 | 대기자금 방치 | 고유계정대 ÷ 총평가금액 ≥ 50% (사용계획·1개월 무변동·교체매매/연금지급 입금은 오탐 배제) |
| S-02 | 저수익 원리금보장 편중 | 고유계정대 + 시중은행 정기예금 = 100% |
| S-03 | 보유상품 만기 임박 | 원리금보장 만기 1개월 이내 (예약변경 가능 시점 = 시스템 제약) |
| S-04 | 보유상품 저수익 | 보유상품 금리 < 당월 제공 가능 상품 금리 (만기 매칭 비교) |
| S-05 | ISA 만기 도래 | ISA 만기 도래·예정, 만기일로부터 60일 이내 |
| S-06 | 이탈 진행 중 | 계약이전(전출) 신청 접수 |
| S-07 | 세액공제 한도 미소진 | 연 개인부담금 납입액 < 세액공제 한도 |
| S-08 | 인출 설계 필요 | 만 55세 이상 + IRP 내 퇴직급여 보유 |
| S-09 | 보유 실적배당상품 수익률 부진 | **절대 임계값 없음** — 동일 연령대 비교그룹 대비 상대 열위로 판정 |
| S-10 | ETF 보유·직접투자 성향 | ETF 보유 또는 단기 테마 직접투자 성향 (증권사 이탈 선행 신호) |
| S-11 | 디폴트옵션 미등록 | 디폴트옵션 미동의 + 현금성 대기자산 보유 (S-01의 재발 원인) |
| S-12 | 위험자산 투자한도 초과 | 주식형 + 주식혼합형 > 적립금의 70% |
| S-13 | 판매중단(성과부진) 펀드 보유 | 성과부진 사유로 신규판매 중단된 펀드 보유 (수치 없이 기계적 판정) |

## 3. 제약 룰 (`10` §3)

| ID | 제약 | 한 줄 |
|---|---|---|
| C-01 | 중도인출 사유 제한 | 법정 6사유 충족 시에만 가능, 최대 90%·기타소득세 16.5% |
| C-02 | 연금개시 연령 제한 | 만 55세 미만 연금수령 불가 → A-09 전략 자체가 불가 |
| C-03 | 연금수령 중 인출 제한 | 연금수령 중 계좌는 중도인출 불가, 해지만 가능 |
| C-04 | 실물이전 불가 상품 | 디폴트옵션·수협 정기예금 등 → 현금화 손실 리스크 |
| C-05 | 특별제공상품 한도 | 월별 제공한도 소진 시 A-02 제안 불가 |
| C-06 | ETF 거래 채널 제한 | ETF 매매는 비대면 채널 전용 → A-03a 전 A-07 선행 |
| C-07 | 채널별 운용지시 범위 | 전화상담센터 위임은 원리금보장 한정. A-03은 실행 장벽이 높음 |
| C-08 | 비대면 펀드 권유 제한 | 비대면에서 특정 펀드 언급 권유는 금소법 위반 소지 → 내점 유도 |
| C-09 | 비대면 접촉 자격 | 동의 고객·동의 채널로만 아웃바운드 가능 → 세 제약 중 최선단 |

> **제약 3층 구조**: C-09(접촉해도 되는가) → C-08(무엇을 말할 수 있는가) → C-07(누가 실행할 수 있는가)

## 4. 진단 관점 (`02`)

## 6. 행동 선택 분기 (`03`)

| ID | 분기 | 기준 |
|---|---|---|
| D1 | 운용 유형 우선 확인 | 희망 유형(원리금보장/실적배당). 상품을 먼저 정하지 않음 |
| D2 | 실적배당 내 세부 분기 | 관여 수준 → a/b/c. 배분은 **자산유형 기준**(K-09), 권고 비율 단일값 고정 안 함 |
| D3 | 변경 시점 판단 | 만기가치 / 중도해지 평가액 / 리밸런싱 예상가치 3항 비교. **만기 = 전환 비용 0 시점** |
| D4 | 이탈 사유별 대응 (S-06) | 사유 5종 — 비대면 불만 / 수수료 / ETF(상품수·매매시간 2축) / 수익률(3분기) / 동반이전 / + 등급 하락 고지 |
| D5 | 인출 전략 선택 (S-08) | 자금 필요 시점·규모 3분기. 연금개시는 **세제 + 수수료 면제** 양쪽 이익 |
