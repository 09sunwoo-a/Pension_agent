# 원천문서 정독 현황 — 정제 작업 트래커

> 문서별 **정독 → 판정 → 확인 → 반영**([CLAUDE.md](CLAUDE.md) §9 절차)의 진행 상태를 추적한다.
> 코어 문서가 아니므로 자유롭게 갱신한다.

## 운영 원칙

1. **미정독 문서를 임의로 정독하지 않는다.** 목록에 있다는 이유로 자동 진행하지 않는다.
2. **사용자가 지정한 문서만, 지정한 순서대로** 정독한다. 지정된 문서는 「정독 대기열」에 등록한다.
3. 정독 1건마다 CLAUDE.md §9(판정 → 수정안 제시 → 사용자 확인 → 반영)를 완료한 뒤,
   이 파일의 **상태와 정독 로그를 갱신**한다.

**상태**: ⬜ 미정독 · 🔜 대기열 등록 · 🔷 정독 진행중 / 부분 반영 · ✅ 정독·반영 완료
