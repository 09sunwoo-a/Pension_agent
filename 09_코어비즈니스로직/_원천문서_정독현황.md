# 원천문서 정독 현황 — 정제 작업 트래커

> 코어 문서(v0.1)는 원천 코퍼스 **전수 훑기**로 뼈대를 세운 상태다.
> 이 파일은 문서별 **정독 → 판단 → 반영**([CLAUDE.md](CLAUDE.md) §5 작업 사이클)의 진행 상태를 추적한다.
> 코어 문서가 아니므로 자유롭게 갱신한다.

**상태**: ⬜ 미정독(훑기만 반영) · 🔷 정독 진행중 · ✅ 정독·정제 완료
**판정 요약 표기**: `신규 n / 강화 n / 대기 n / 기각` (CLAUDE.md §5-3의 결론 집계)

**우선순위 원칙**
- **P1** — 본부 공식 방법론·타깃 정의 문서: 이미 코어에 많이 인용됨 → 정독으로 `검토중` 항목 확정 승격과 임계값 검증 효과가 가장 큼
- **P2** — 교육자료·현장 핫팁: 구조 후보(분기·시퀀스·함정)와 Evidence의 주 공급원
- **P3** — 공개 팩트·주기 갱신 재료·파생물: 코어 직접 반영보다 검증·상호참조 용도
