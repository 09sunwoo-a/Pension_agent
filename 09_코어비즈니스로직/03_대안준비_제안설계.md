# 03. 대안 준비·제안 설계

> **v0.1** (2026-08-24) · 세부 단계 구조는 원천 코퍼스(01~05, 08) 전수 훑기에서 귀납 도출.
>
> **질문**: 무엇을, 어떤 순서로, 어떤 근거와 함께 제안할 것인가? · **입력**: 진단 결과 + 이달의 상품·금리 풀 · **출력**: 제안 패키지(제안 1+예비 1, 근거, 반론 대비) · **제품**: 개인별 솔루션 화면(제안부)
>
> 원칙: 접촉 전에 재료를 손에 들고 시작한다. 재료는 항상 "이번 달(주) 기준".

## 세부 단계 개요

```
3-1. 후보 생성        진단 결과 → 대안 후보 매핑
3-2. 적합성·제약 검증   이 고객에게 이 제안이 가능한가
3-3. 구성 원칙        제안의 형태를 다듬는 규칙
3-4. 우선순위 결정     "오늘의 제안 1개 + 예비 1개"
3-5. 근거 패키징      수치·시뮬레이션·문서화
3-6. 반론·리스크 대비   예상 반론과 사전고지 목록
```

---

## 3-1. 후보 생성 — 진단 → 표준 대안 매핑

| 진단 결과 | 표준 대안 | 근거 |
|---|---|---|
| 방치 현금성 | 현 금리 안내 → 운용지시 (예금 or 펀드) | [S1][KPI] |
| 예금 만기 + 안전 선호 | 동일 안전성·고금리 재예치 (저축은행·GIC) | [KPI] |
| 예금 만기 + 분산 가능 | 채권 비중 높은 TDF·채권형부터 일부 편입 | [KPI] |
| 부진 펀드 보유 | 수익률 비교 후 우수 펀드·ETF 교체 | [KPI] |
| 수익률 하위 | 피어 비교 → 포트폴리오 분산 | [KPI] |
| 성향-운용 불일치 | 불일치 자체를 개선 근거로 등급 조정 | [오늘] |
| 월 현금흐름 니즈 | 월분배형·배당 ETF (분배주기·보수 기준) | [교육:월배당][핫팁] |
| 직접 운용 부담 | 디폴트옵션·AI일임 (제약 확인 전제) | [S1][공개] |

- **시황 시나리오 매핑**: 월간 이벤트별 긍정/기본/부정 시나리오에 매수·리밸런싱 상품이 미리 매핑된 풀 활용 [시황]
- **성향별 모델 포트폴리오**: 월 갱신되는 성향 5단계 포트폴리오(구성·비중·기대수익·변동성)를 제안 골격으로 [시황]
- **연금수령(예정) 고객 전용 풀**: 수령기 고객은 별도 포트폴리오(단기채 중심)로 분리 설계 [시황]

## 3-2. 적합성·제약 검증

- **성향 보존**: 위험 수준을 바꾸라고 하지 않는다. 같은 위험 등급 안에서의 개선이 기본기 [S1]
- **투자한도**: 위험자산 70% 한도, 적격 TDF·디폴트옵션·채권혼합 ETF는 100% 예외 — 한도 내 조합 설계 (예: 주식형 70+채권혼합 30) [보물][핫팁:최수인]
- **계좌 상태·자격**: 2-7의 플래그와 대조 (연금개시·지급설계·일임 중·이전 자격) — 설득 후 거래가 튕기는 참사 방지
- **채널 판매 제약**: 이 상품이 이 채널(창구/앱/전화센터)에서 실행 가능한가 (전화센터는 예금→예금만 등) [KPI][핫팁]
- **예금자보호 한도 분산**: 고액 원리금보장은 기관별 5천만원 한도로 분산 구성 [교육:상품5종]
- **월 한도·최소금액**: 특별제공상품 월 잔여한도, 최소 거래금액(ELB 5천만원 등) 확인 [S1]

## 3-3. 구성 원칙 — 제안의 형태

- **관여도 사다리**: 직접 고르고 싶다→ETF / 맡기고 싶다→TDF / 못 고르겠다→추천 포트폴리오·디폴트옵션 [S1]
- **부분 수용(90/10)**: 고객 욕구(특정 테마·ETF)를 부정하지 않고 최소 90% 분산 + 10% 허용으로 흡수 [교육:통합이탈]
- **규모 축소 + 가역성**: 거부감 있는 고객엔 "일부만(500만~1천만) + 되돌릴 수 있음 + 6개월 뒤 재점검"으로 재제안 [핫팁][S1 계열]
- **분할 투입**: 일괄 전환 부담 고객은 적립식 분할 매수로 설계 (단, 연금수령 중 고객 제외) [핫팁:강현애]
- **계좌 경로 설계**: 가입일 승계가 걸린 이전은 0원 계좌 신규 후 수령, 연금개시 계좌 복수 이전은 건별 순차, 재취업 예정자는 3단(개시/퇴직용/적립용) 분리 [보물][핫팁:진승현·김정희]
- **상품 축 확장**: 니즈에 따라 IRP 단독 vs 연금저축+IRP 조합 등 계좌 조합 선택 [핫팁:박수연]

## 3-4. 우선순위 결정 — "오늘의 제안 1개 + 예비 1개"

- 제안 나열은 안 하느니만 못하다 — 핵심 1개를 선정하고 예비 1개를 대기시킨다 [기능정의·핫팁:양혜련]
- 복수 니즈면 핵심 니즈(2-5)에 대응하는 제안이 1번, 기한이 걸린 것이 있으면 기한 우선
- 보류된 제안은 소멸이 아니라 후속 예약(5-3)으로 이관

## 3-5. 근거 패키징

- **원 단위 금액 환산**: 비율이 아니라 금액 ("16.5% 공제" ❌ → "148만원 환급" ⭕, "못 받은 이자 99만원") [핫팁 다수]
- **개인화 시뮬레이션**: 절세액·환급액·중도해지 손익을 이 고객 수치로 계산해서 장착 [핫팁:김재·류혜진]
- **기준시점 부착**: 모든 수치에 'YY.M월 기준 — 기준일 없는 수치는 인용 불가 [S1][시황]
- **신뢰 라벨**: 본부공식/현장팁/대외공개(고객 제시 가능 여부) 구분 표시 [인사]
- **비교 근거**: 피어 운용현황, 사업자별 수익률·수수료 비교표 [팩트][마스터-은]
- **문서화(제안서)**: 보유상품 정리표 + 단계별 실행안 + 상품·금리표 — 고액 건의 결정타이자 최대 병목 (자동화 1순위) [핫팁:양혜련·김정희·엄주원]

## 3-6. 반론·리스크 대비

- **예상 반론 2~3개 + 답**: 이 고객 프로필에서 나올 법한 것만 선별해 완성 대사로 준비 (전체 카드 라이브러리에서 선택) [기능정의][교육 5종]
- **사전고지 목록**: 제안과 세트로 나가야 할 고지 문구(원금 차감 가능, 지급 3영업일, 신청금액은 세전, 이전 시 원천기관 수수료 차감 등) — 미고지는 민원 [핫팁:진승현]
- **이탈 상담용**: 이탈 사유 4~5분류별 대응 논리 팩 (ETF 라인업/수익률/수수료/관리 소홀/대출 동반) [교육][보물]
