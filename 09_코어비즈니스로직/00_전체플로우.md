# 00. 전체 플로우 — 퇴직연금 사후관리 에이전트

> **v0.3** (2026-08-24) · 서비스 전체의 큰 플로우를 정의하는 기준 문서.
> 단계별 방법론은 01~05, 조건식·액션 정의는 10. 수정 규칙은 [CLAUDE.md](CLAUDE.md).

## 서비스 정의

**사후관리가 필요한 고객을 찾아 → 자산·상황 맥락을 분석해 → 적절한 솔루션과 화법을 생성하여 → 영업점 직원에게 제공하는 에이전트.**

- **사용자**: 영업점 직원 (1차 수혜자: 신입~중견)
- **대상**: 당행 개인형IRP 보유 고객의 **사후관리** (신규유치·기업형 DB/DC는 범위 밖)
- 코어 로직은 **일반론**(어느 퇴직연금 사업자에게나 성립하는 방법론)으로 정제한다.
  은행 이익 전술(락인 유도·KPI 득점 등)은 코어에서 제외 — 추후 「리텐션 전술」 트랙에서 별도 관리.

## 제품 구조

```
대시보드 (메인화면)
 └─ 오늘의 타겟리스트
     └─ [클릭] → 개인별 솔루션 화면 + 상담 대응 챗봇
                    └─ 장바구니 → CRM 기록 · 후속 일정
```

## 비즈니스 플로우: 5단계 순환

```
1. 트리거 ──→ 2. 진단 ──→ 3. 대안 준비 ──→ 4. 개입 ──→ 5. 기록·연계
   (가설)      (검증+심화)     (제안 설계)      (상담 실행)    (다음 사이클의 입력)
      ↑______________________________________________________|
```

| 단계 | 질문 | 출력 | 제품 |
|---|---|---|---|
| 1 [트리거](01_타겟고객선정.md) | 누구에게 지금 주의를 쓸 것인가 | 우선순위 리스트 + 행별 "왜 지금" 가설 | 대시보드 타겟리스트 |
| 2 [진단](02_진단_종합상태읽기.md) | 이 고객의 전체 그림은 무엇인가 | 종합 상태 + 검증된 접촉 명분 | 솔루션 화면 (브리핑부) |
| 3 [대안 준비](03_대안준비_제안설계.md) | 무엇을 어떤 순서로 제안하는가 | 제안 1 + 예비 1 · 근거 · 반론 대비 | 솔루션 화면 (제안부) |
| 4 [개입](04_개입_상담실행.md) | 어떻게, 어디까지 말하는가 | 합의/보류/거절 + 실행 | 상담 대응 챗봇 |
| 5 [기록·연계](05_기록연계.md) | 상담을 다음 상담의 재료로 | CRM 기록 · 후속 일정 · 진행 추적 | 장바구니 → CRM |

- 리스트의 각 행은 결론이 아니라 **가설**이다. 1→2 전환(클릭)이 저해상도 → 고해상도 진단의 전환점.
- 5의 출력(기록·예약)이 1(이벤트 트리거)과 2(진단 재료)의 입력이 되어 **순환**한다.
- 진단·솔루션 로직은 트리거와 **독립 실행 가능**해야 한다 (인바운드 대응).

## 공유 자산 — 단계는 프로세스, 룰은 자산이다

같은 조건식("현금성 편중")이 1단계에선 트리거로, 2단계에선 진단 항목으로 재사용된다.
단계 문서마다 정의하면 임계값 드리프트가 생기므로, 정의는 [10_룰_카탈로그.md](10_룰_카탈로그.md) 한 곳에만 둔다.

```
        ┌────────────────────────────────────────┐
        │  10. 룰 카탈로그 (단일 정의처)               │
        │  상태 판정 룰(R-): 저해상도/고해상도 조건식 쌍  │
        │  액션(A-): 실행 내용·제약·경로·재료           │
        │  연결: 룰의 후보 액션 필드 (N:M, 분기 조건)    │
        └───────┬───────────┬───────────┬────────┘
     트리거 승격 룰 │    전체 룰 │           │ 룰→액션 매핑
            ▼           ▼           ▼
       [1. 트리거]   [2. 진단]   [3. 대안 준비]
       모집단 스캔    개인 정밀 평가  후보 생성+적합성 검증
```

그 외 공유 자산: 주기 갱신 재료(월간 상품·금리·포트폴리오 / 주간 시황 / 분기 부진 리스트) · 화법 카드 · 계산기 · 사전고지 문구집

## 관통 원칙 (모든 단계 공통)

| # | 원칙 |
|---|---|
| G1 | 수치는 **원 단위 금액 + 기준시점**과 함께 산다 |
| G2 | 모든 재료에 **신뢰 라벨** (본부공식 / 현장팁 / 대외공개=고객 제시 가능) |
| G3 | 출력은 **완성형** — 지시가 아니라 대사, 화면·순서까지 |
| G4 | **"하지 말 것"이 "할 것"만큼 중요** — 금지 용어·제외 조건·사전 고지 병기 |
| G5 | 진단·설득의 단위는 절대값이 아니라 **격차** (기준선과의 거리) |
| G6 | **위험 수준은 고객이, 상품은 은행이** 정한다 |
| G7 | 재료의 **갱신 주기**를 시스템이 안다 |
