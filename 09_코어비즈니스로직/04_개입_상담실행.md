# 04. 개입·상담 실행

> **v0.2** (2026-08-24) · **질문**: 어떻게 말하고, 어디까지 말하고, 합의를 어떻게 실행으로 잇는가? · **입력**: 제안 패키지 + 상담 중 고객 반응 · **출력**: 합의/보류/거절 + 실행

## 4-1. 접촉 개시

- **접촉 명분 = 고객 상태 사실**: "좋은 상품이 나와서"가 아니라 "고객님 계좌가 지금 이런 상태라서"
- **정보 비대칭 오프너**: 고객이 모르는 자기 현황(2-4)을 보여주며 진입
- 통화 표준 구조: 인사·본인확인 → 통화가능 확인(소요시간 제시) → 용건 → 마무리 — 각 단계에 이탈 분기(재약속)
- 첫 접촉 전 선행 접점(전담직원 인사 등)으로 문턱 낮추기

## 4-2. 화법 전개

- **분기 질문**: 위험 수준의 결정권은 고객에게(G6) — 지식의 분기 조건을 질문으로 뒤집는다
- **존중 프레임**: 고객의 현재 선택을 먼저 인정한 뒤, 같은 성향 내 개선 제안
- **이탈 상담 시퀀스**: 경청(사유 파악) → 관리 미흡 사과 → 사유별 대안 → 결정 유보 요청
- **재정의·분리 화법**: 위험=변동성 재정의 + 자금 기간 분기 · 타사 선택의 합리성 인정 후 판단 기준 분리
- 유형·연령별 소구점 변주 · 민감 상태(수익률 저조)는 지적 금지 — 관리 프레임과 개선안 중심

## 4-3. 도구 사용

- **계산기 위임**: 유불리 판단은 화법이 아니라 정량 도구로 즉석 산출
- 조회 시연 (고객 동의하에 함께 실사) · 실증 데이터 (피어·공시 등 제3자 근거)

## 4-4. 준수 사항 (하드 룰)

- **채널이 구체성 한도를 결정**: 유선/비대면은 특정 상품 권유 금지 — 유형까지만, 구체 제안은 내점 유도
- 완전판매·적합성: 성향에 맞는 상품만 제시, 창구 투자상품은 녹취 절차
- 동의 채널 준수 (R-F05) · 금지 용어 치환 · 고객 금융거래정보 언급 금지
- **사전고지 세트 발화**: 제안 문장과 고지 문장(3-6)은 항상 세트

## 4-5. 합의 → 실행

- 경로 분기: 비대면 가능→거래 URL 셀프 실행 / 불가→내점(담당자 지정) / 내점도 어려움→전담조직 연계(처리 범위 제약) / 복잡 니즈→전문 조직 격상
- **실행 함정의 선제 처리**: 선행조건(R-F07) 확인 먼저 · 거래 시퀀스·기한·대사(對査)는 액션별 「실행 경로·함정」 필드([10](10_룰_카탈로그.md)) 준수

## 4-6. 거절·보류 처리

- **끝나지 않게 끝내기**: 즉답 회피 고객엔 안내장·URL로 여운 + 재접촉 약속
- 규모 축소 재제안(3-3) · 보류 사유와 재접촉 시점을 담아 5단계로 이관
- 퇴로 화법: 최종 거절에도 감사 + 복귀 문턱 낮추기
