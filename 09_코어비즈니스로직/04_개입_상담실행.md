# 04. 개입·상담 실행

> **v0.1** (2026-08-24) · 세부 단계 구조는 원천 코퍼스(01~05, 08) 전수 훑기에서 귀납 도출.
>
> **질문**: 어떻게 말하고, 어디까지 말하고, 합의를 어떻게 실행으로 잇는가? · **입력**: 제안 패키지 + 상담 중 고객 반응 · **출력**: 합의/보류/거절 + 실행 · **제품**: 상담 대응 챗봇

## 세부 단계 개요

```
4-1. 접촉 개시        관계 열기와 명분 제시
4-2. 화법 전개        분기·설득의 구조
4-3. 도구 사용        계산·조회·실증
4-4. 준수 사항        컴플라이언스·금지 규칙 (하드 룰)
4-5. 합의 → 실행      경로 분기와 실행 함정 처리
4-6. 거절·보류 처리    끝나지 않게 끝내기
```

---

## 4-1. 접촉 개시

- **관계 워밍업**: 첫 접촉 전 전담직원 인사 메시지 등 선행 접점으로 문턱 낮추기 [리마2021]
- **통화 표준 구조**: ①인사·본인확인 → ②통화가능 확인(+정확한 소요시간 제시 "3분이면") → ③용건 → ④마무리. 각 단계에 이탈 분기(본인 아님/통화 불가→재약속) [오늘]
- **접촉 명분 = 고객 상태 사실**: "좋은 상품이 나와서"가 아니라 "고객님 계좌가 지금 이런 상태라서" [S1][KPI]
- **정보 비대칭 오프너**: 고객이 모르는 자기 현황(납입액·공제액·방치 자산)을 보여주며 진입 — 현장 검증된 최강 오프너 [핫팁:서영주]

## 4-2. 화법 전개

- **분기 질문**: 위험 수준의 결정권은 고객에게 — "원리금보장 원하세요, 실적배당 원하세요?" 지식의 분기 조건을 질문으로 뒤집는다 [S1]
- **존중 프레임**: 고객의 현재 선택을 먼저 인정("펀드가 변동성이 커서 예금으로 하시는 거죠?") 후 같은 성향 내 개선 제안 [KPI]
- **이탈 상담 시퀀스**: 경청(사유 파악) → 관리 미흡 사과 → 사유별 대안 → **결정 유보 요청**("이전 결정 전에 상담 한 번만") [교육:VIP이탈][보물]
- **인정 후 분리**: 타사 선택의 합리성을 인정한 뒤, 연금은 판단 기준이 다른 상품임을 분리 설득 [교육:대출이탈]
- **재정의 화법**: "위험하지 않나" → 위험=변동성 재정의 + "1~2년 내 쓸 돈인가, 30년 자산인가" 기간 분기 [교육:통합이탈]
- **유형·연령별 변주**: 연령대(2030/40/50+)·고객 유형(고액자산가 등)별 소구점 분기 [핫팁:최수인·신은지]
- **민감 상태 접근**: 수익률 저조 고객은 지적 금지 — "전담직원 인사 + 정기 관리" 프레임, 개선안 중심. 부진 펀드는 감정 인정 후 구조적 근거 [KPI]

## 4-3. 도구 사용

- **계산기 위임**: 유불리 판단(중도해지 vs 만기, 절세액, 미신청금액)은 화법이 아니라 정량 도구로 즉석 산출 — "계산해주면 전문가" [S1][핫팁:김재]
- **조회 시연**: 고객 동의하에 함께 화면·앱을 열어 실사 (타행 보유상품, 운용현황) [핫팁:신은지]
- **실증 데이터**: 피어 운용현황, 공시 수익률 비교 등 제3자 근거 제시 [KPI][팩트]

## 4-4. 준수 사항 (하드 룰)

- **채널이 구체성 한도를 결정**: 유선/비대면에서 특정 펀드 권유 금지(금소법 소지) — 상품 유형까지만, 구체 제안은 내점 유도 [KPI]
- **완전판매·적합성**: 성향에 맞는 상품만 제시, 창구 투자상품은 녹취 절차 [교육:통합이탈][핫팁]
- **동의 채널 준수**: 마케팅 동의 고객에게 동의된 채널로만 [공문]
- **금지 용어**: "고유계정대" → "현금성자산"/"운용지시가 되지 않는 자산" [KPI]
- **개인정보 언급 금지**: 카드사용·거래내역 등 금융거래정보 언급은 민원 소지 [오늘]
- **사전고지 세트 발화**: 제안 문장과 고지 문장은 항상 세트 (3-6 목록) [핫팁:진승현]

## 4-5. 합의 → 실행

### 실행 경로 분기

| 고객 상황 | 경로 | 비고 |
|---|---|---|
| 비대면 가능 | 거래 URL 발송 → 셀프 실행 | 처리 빠름, 녹취 부담 회피 [KPI][핫팁] |
| 비대면 불가 | 내점 유도 (담당자 지정) | [KPI] |
| 내점도 어려움 | 전담 상담조직 연계 | 처리 범위 제약 (예금→예금만) [KPI] |
| 복잡 니즈(세무 등) | 전문 조직 격상 (세무사·전문센터 동반) | [교육:IRP사례][보물] |

### 실행 함정의 선제 처리 (현장 검증 실패 사례 기반)

- **선행조건 먼저**: 상대기관 비밀번호 등록, 서류 사전 징구 — 미비 시 '기타 거절' [핫팁:김현정]
- **확인전화 예고**: 이전 시 원천기관의 의사확인(최대 3차) 전화를 사전 고지 — 무응답만으로 자동 거절된 실사례 [핫팁:신은지]
- **거래 시퀀스 준수**: 디폴트옵션 상향은 2단계 거래(등록변경+보유상품변경) — 하나만 하면 절반 처리 / 실물이전은 [선해지→신규+이전신청→완료 전 입금 금지→완료 후 매수] 순서 [오늘 계열][핫팁:이주영]
- **기한 있는 실행의 대사(對査)**: 과세이연 5단계(정보등록→입금→환급신청→정보수정→환급 입금), 입금액=요청금액 일치 확인 [핫팁:류수빈]
- **실행 방식 선택**: 보유상품은 교체매매, 만기 전 상품은 예약변경(1개월 전부터), 원리금보장 매수는 월 단위 금리 확정 감안(월말 매수 주의) [핫팁:박서영]

## 4-6. 거절·보류 처리

- **끝나지 않게 끝내기**: 즉답 회피 고객엔 안내장·URL 발송으로 여운 + 재접촉 약속 [핫팁:장예나·이채희]
- **규모 축소 재제안**: 거부 시 "일부만 + 되돌릴 수 있음"으로 낮춰서 다시 [핫팁]
- **보류의 자산화**: 보류 사유와 재접촉 시점(만기 후, 자금 유입 후)을 장바구니에 담아 5단계로 이관
- **퇴로 화법**: 최종 거절에도 감사 + 연락처 + 복귀 문턱 낮추기 ("언제든 다시 찾아주시면") [오늘][보물]
