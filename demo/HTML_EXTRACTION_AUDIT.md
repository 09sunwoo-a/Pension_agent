## 2. Extraction Scope

확인한 영역(모두 JS 객체 + 마크업 바인딩을 대조):

- 인트로 스플래시 · 부점 브리핑(고정 텍스트) · «생성 로직» 다이어그램(PNG 판독) · 사후관리 현황 KPI · KPI 필터 ·
  고객 리스트 행(`QMETA`) · 조건 추출 · 엑셀 · 검색(`DIR` 24명)
- 고객 상세: 헤더/배지 · 고객 정보(`profileOf`) · IRP 계좌현황(도넛·세액공제 게이지) · 운용 현황(`hold`)
- AI 브리핑 `BRIEFS` S1~S5 전량 (3명)
- 실시간 상담 `QA` 전량 — 추천 질문 · 키워드 매칭 · 답변 블록 · 근거 · 가드 · CTA · 액션 토스트/딥링크 (3명)
- 대응 가이드 챗 `SCR`/`COMMON`/`GEN` (대시보드 전용 15명) — 존재 확인, 요약만 수록
- 카탈로그 `RECO`(DO 4종) · `FUNDS`(17종) — 렌더 안 됨을 확인
- dormant 데이터: `head`/`metrics`/`act`/`why`/`tags`/`ai`/`propose`/`pick`/`tip`/`docs`/`touch`/`cmp`/`refs`/`simBrief`/`BRIEF_SEGS`
  — 마크업 `{{ }}` 바인딩 부재를 grep 으로 확인
- «답변 흐름» 다이어그램(PNG 판독)

확인하지 않은 것: CSS·폰트·애니메이션 타이밍(의미 구조와 무관).
