# DEMO-02 이수민

HTML 내부 id `lsm`. 대시보드 2순위 · «신규 선정».

## 1. Case Concept

`Case Intent` — 원리금보장 88%로 운용해 온 위험중립형 51세 고객에게 **IRP 정기예금 7,000만원의 9/26 만기
(D-22)** 와 **6월 만기 후 약 10주째 운용지시 없이 대기 중인 현금성자산 1,000만원**, **디폴트옵션 미등록**
을 묶어, «만기상품 예약변경은 만기 1개월 전부터 가능» 이라는 제도 시점을 근거로 지금 상담을 권하는 Case.
S3는 정기예금·GIC 재운용을 기본으로 두고 일부 실적배당형 또는 디폴트옵션으로 운용 공백을 줄이는 제안이며,
실시간 상담은 «타행 대비 수익률» «그냥 예금으로 둬도 될까» 같은 원리금보장 편중 고객의 전형적 반응에 대한
화법(공시 1위 · 72의 법칙 · 국민연금 비교)과 «DO 등록해도 기존 1,000만원은 자동 운용되지 않는다» 는 제도
설명을 시연한다.

## 8. AI Brief AS-IS

### 고객 상황 (S1)
- Main: **IRP 정기예금 7,000만원이 9월 26일 만기 예정**입니다.
- Supporting: 지난 6월 만기된 **1,000만원은 약 10주간 운용지시 없이 현금성자산**으로 남아 있으며, 최근
  스타뱅킹에서 **IRP 수익률과 정기예금 금리를 조회**했습니다.

### 핵심 관리 포인트 (S2)

### Q&A

**q1 «타행 대비 KB IRP 수익률은?» — 상담 화법**
- 상태: 공시 자료를 찾고 있어요 → 상담 화법을 찾고 있어요
- Lead: 구체적인 수익률 수치(몇 %)는 자료에 없어요. 다만 공시 근거로 순위를 제시하고, 수익률 논의를 장기 관리
  관점으로 옮기는 접근법은 자료에 있으니 그걸로 대응할 수 있어요.
- 설명: 고객은 «국민은행이 정말 더 나은가» 를 확인하고 싶은 것 → 공신력 있는 공시 결과 제시 → 단기 수익률
  비교에서 장기 관리 경험으로 논점 이동.
- 인용 1 («고객에게 이렇게 말씀해 보세요»): 2026년 1분기 금융감독원 발표에 따르면, KB국민은행이 IRP 실적배당형
  부문에서 최근 1년, 3년, 5년, 7년 수익률 모두 주요 시중은행 가운데 가장 높은 수익률을 기록했습니다. 이는 꾸준한
  고객관리로 만들어낸 결과물이죠^^
- 인용 2: IRP는 어디에 가입했느냐보다 어떻게 관리받느냐가 더 중요한 상품입니다. … 온국민 투자가이드와 추천
  포트폴리오도 안내드리고 시장상황에 맞춰 리밸런싱까지 상담해드리고 있습니다. 저희가 이번 1분기 공시기준, IRP
  실적배당형 수익률 1위인 이유이기도 하죠^^

**q2 «그냥 예금으로 둬도 될까?» — 상담 화법**
- 상태: 상담 화법을 찾고 있어요 → 논거를 정리하고 있어요
- Lead: «그냥 예금으로 둬도 되지 않나요?»는 원리금보장 편중 고객에게 가장 자주 나오는 말이에요. 이 질문에는 72의
  법칙으로 숫자를 직접 보여주는 게 효과적이에요 — 안전하게 두는 것이 잘 관리하는 것이라는 통념을 흔들어야 다음
  대화가 열리거든요.
- 72의 법칙: 72 ÷ 연간 수익률 = 두 배 기간. 연 3% → 24년(은퇴 후), 연 7% → 약 10년.
- 국민연금 비교: 국민연금 수익률 연 6.21%, 정기예금에 전혀 투자하지 않고 자산배분. 퇴직연금 자산의 90% 이상은
  정기예금, 수익률 연 2.35%.
- 인용: 고객님, 72를 수익률로 나누면 돈이 두 배 되는 기간이 나와요. 지금 원리금보장형 수준인 연 3%면 24년이
  걸리는데 … 국민연금은 연 6.21% 수익률을 내고 있거든요. … 사실 국민연금은 정기예금에 전혀 투자하지 않아요. …

  vs 퇴직연금 2.35% 논거) · 연금 투자, 이거는 알고 하자 · KB StarLearn 직원교육 (72의 법칙)
- 가드 적용.

**q3 «DO 등록하면 1천만원도 자동운용?» — 제도 안내**
- 상태: 관련 제도를 확인하고 있어요 → 근거 자료를 확인하고 있어요
- Lead: 기존 적립금 1,000만원은 디폴트옵션 등록만으로 자동으로 운용되지는 않아요.
- 적용 케이스: ① 적립금이 최초로 입금된 후 2주간 운용지시가 없을 때 ② 기존 운용 상품 만기 후 4주 무지시 → 안내 →
  2주 후 적용. 이미 운용 중인 적립금은 해당 없음 → 1,000만원은 직접 운용지시 필요.
- 옵트인: 대기 기간 없이 즉시 운용지시 가능. DO 미운용 상태면 원하는 상품으로 바로 지정, 이미 DO 운용 중이면 같은
  상품으로만. 상품을 바꾼다고 기존 적립금을 먼저 매도해야 하는 건 아님.
- ⚠ caution: «알아서 굴러가냐» 질문이면 1,000만원 지시를 직접 내려야 함을 먼저 짚고 옵트인 안내.
- 출처: 본부 공식 자료 / 근거: 연금사업부(상품) 오늘의할일 스크립트 · 연금사업부(상품) · 2023~24 추정 (디폴트옵션

- Follow: 고객이 스타뱅킹에서 직접 하는 경로가 있어?
- 가드 적용.

## 11. Case Design Intent

`Inference from HTML`:

1. **만기 + 방치 + 미등록의 결합** — 세 신호를 «운용 공백» 한 주제로 묶는다.
2. **제도 시점 활용** — 예약변경 가능 구간(만기 1개월 전)이 «왜 지금» 이다.
3. **재발 방지 프레임** — 대기 상황이 반복되지 않도록 DO 등록을 제안하되, «등록만으로 기존 1,000만원은 안 움직인다»
  는 한계를 S3 foot·챗 q3 에서 이중으로 짚는다.
4. **화법 등급 구분** — 화법 답변은 «직원 교육자료» 출처 + «본부 확정 지침이 아닙니다» 가드.
5. **성향 범위 내 제안** — 실적배당형 후보를 «위험중립형 범위 내» 로 한정.
6. **업무 화면 연결** — 금리 확인 화면과 대기자금 관리 화면.
