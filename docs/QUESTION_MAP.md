# 대화형 에이전트가 답하는 질문

영업점 직원이 상담 전·중·후에 대화형 에이전트에 물을 수 있는 질문을 **구분 4 · 항목 22 · 질문 135개**로 폈다.
직원이 그대로 치는 말이고, 고른 예시가 아니라 **지금 실제로 답이 나오는 질문**이다.

**질문마다 실제로 돌려 받은 답이 함께 있다** — `docs/QUESTION_MAP.xlsx` 의 「실측 답변」 칸.
이 문서는 질문 목록이고, 답을 나란히 보려면 xlsx 를 연다.

> 에이전트는 **행원들이 정리해 둔 행내 지식베이스**와 **열려 있는 고객의 브리핑 재료**만을
> 근거로 답한다. 근거에 없는 수치·상품·요건은 지어내지 않고, 없으면 없다고 답한다.

## 어떻게 읽나

| | |
|---|---|
| **구분** | 상담 시점 — 상담 전 · 상담 중 · 상담 후 |
| **항목** | 그 시점에 에이전트가 하는 일 |
| **질문** | 직원이 그대로 치는 말. 「이 고객」은 화면에 열려 있는 고객을 가리킨다 |
| **↑ 앞 턴** | 그 앞에 같은 상담에서 먼저 물은 말 — 대화가 이어진다는 뜻이다 |
| **↳ 〃** | 윗줄과 **글자가 같은 질문**을 다른 고객에게 물은 행. 고객 상태가 다르면 답이 갈리는 것을 보는 자리다(답은 xlsx) |
