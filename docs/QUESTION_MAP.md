# 대화형 질문 지도 — 능력 셀 × 갈래

대화형 에이전트가 답할 수 있는 «질문의 종류»를 능력 단위로 편 표다. 한 행이 능력 셀 하나이고,
같은 능력이 고객 상태에 따라 갈리면 **갈래마다 한 행**이다. 시연에 쓸 질문을 여기서 고르고,
«아직 안 물어본 자리»를 「기존 커버」 칸의 **미커버**로 찾는다.

> 이 문서는 손으로 쓴 초안이다(생성물이 아니다). 「나와야 할 것」은 기대이지 보장이 아니고,
> 문장은 매번 LLM 이 새로 쓴다 — 시연에 올릴 질문은 반드시 리허설로 실측한다.
> 실행: `cd src && python -m tests.debug -c <고객 ID> --debug "<질문>"`
