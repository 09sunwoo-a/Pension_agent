# 고객별 예상질문 QA — 더미 고객 12명

시연 고객 12명 전원에게 **직원이 실제로 물을 법한 말**을 던져 «답이 잘 나오는가»를 보는
대본이다. 시연 대본(`DEMO_SCENARIO.md` · `DEMO_CUSTOMER_SCENARIOS.md` · `DEMO_REVIEW.md`)이
보여줄 장면을 고른 것이라면, 이 문서는 **원장에 있는 값·기록·상태를 고객마다 빠짐없이
묻는 것**이 목적이다. 라이브러리가 다루지 않은 7명(김현수·박지민·이준호·최서윤·한지우·
오세훈·윤가영)은 여기서 처음 묻고, 라이브러리의 5명(정민석·송도윤·김서연·박정호·이수민)은
그쪽과 겹치지 않는 질문으로 채웠다.

> 이 문서는 손으로 쓴다(생성물이 아니다). 질문은 `src/tests/debug/scenarios.py::QA`,
> 턴마다의 «기대»는 같은 파일의 `QA_EXPECT` 에 있다 — 실행기가 질문 아래 그 줄을 붙여
> 찍는다. **기대는 코드가 아는 값으로만 적었다**(원장 · 세션 저장소의 상담 기록 · 성립
> 요건 · 열려 있는 안내 콘텐츠 · 타겟 룰베이스 원문). 문장은 매번 LLM 이 새로 쓰므로
> «그 값이 그 뜻으로 답에 들어 있는가»를 사람이 읽고 판정한다. 채점은 코드가 하지 않는다
> (`reps.py` 머리말 「채점하지 않는다」).

## 실행

```bash
cd src
python -m scripts.prebuild_briefings                       # 먼저 — 브리핑 12편을 미리 만든다(아래 ②)
PENSION_TODAY=2026-09-07 python -m tests.debug.reps qa                    # 12명 83턴
PENSION_TODAY=2026-09-07 python -m tests.debug.reps qa 김현수 윤가영 --why   # 고객 골라서 · 무엇을 찾아봤나
PENSION_TODAY=2026-09-07 python -m tests.debug.reps qa 3 --why --show-llm   # 블록 번호로 · 폐기된 생성문까지
PENSION_TODAY=2026-09-07 python -m tests.debug.reps qa --brief             # 요약표만
```

턴 하나만 따로 볼 때: `python -m tests.debug -c <고객ID> --debug "<질문>"`.

**돌리기 전에 확인할 것 셋.**

① **오늘을 `2026-09-07` 로 고정한다.** 기대에 적은 잔여일수(이준호 만기 D-3 · 오세훈 D-11 ·
이수민 D-19 · 송도윤 ISA D-13 · 한지우 ISA 이틀 경과 · 박지민 연말까지 115일)가 그 날짜
기준이다. `reps` 의 기본 고정값(2026-08-24)으로 돌리면 이수민의 만기 요건이 안 서고(D-33),
한지우의 ISA 가 만기 «전»(D-12)이 되어 기대가 어긋난다. 브리핑 캐시의 지문에도 오늘이
들어가므로(`briefing_store.fingerprint`) ②의 사전 생성도 같은 날짜로 돌린다 — 실제 날짜가
9/7 이면 환경변수 없이 돌린 것과 같다.

② **브리핑을 미리 만든다.** 고객 블록의 첫 턴은 화면을 여는 자리라 브리핑(순차 LLM 11회)을
생성한다. 무료 gemma 키는 분당 토큰 한도가 있어, 이 11회가 한도를 소진하면 **첫 턴의 답변
작성이 429 로 죽는다**(실측 — 김현수 첫 턴 55초 중 46초가 브리핑 생성, 그 직후 compose 가
429 로 «LLM 호출 실패» 안내). `scripts.prebuild_briefings` 를 한 번 돌려 두면 읽어 쓴다.
그래도 429 가 나면 `LLM_RETRY_ATTEMPTS=10` 과 `--pause=20`(턴 사이 20초)으로 돌린다.

③ **상담 기록 픽스처가 그대로인지 본다.** `reps` 는 실행 전후로 `session_data/` 를 통째로
되돌리지만, `tests.debug` CLI 나 Streamlit 으로 연습한 턴은 남는다 — 남으면 「지난 상담에서
무슨 얘기 했지?」가 방금 연습을 «지난 상담»으로 읽는다. `git status src/session_data/` 가
깨끗해야 한다(기록 없는 고객 김현수·김서연·이수민은 파일 자체가 없는 것이 정상).
