# 에이전트 기능정의 — 행원 참고자료 4종 (영업 전·중·후·평상시)

에이전트가 행원에게 **무엇을 · 언제 · 어떤 형태로** 제공하는지의 기준 문서.
핵심 관점은 "무엇을"보다 **"언제, 어떤 형태로"** — 영업의 시간축에 따라 필요한 것이 전혀 다르다.

| 시점 | 형태 |
|---|---|
| ① 영업 전 | AI 브리핑 (30초 간단) |
| ② 영업 중 | 채팅형 인터페이스 |
| ③ 영업 후 | 장바구니 · 메모 · CRM 연계 |
| ④ 평상시 | 대시보드 |

---

## 0. 에이전트 구성 원칙

모든 시점·모든 산출물에 공통으로 적용되는 원칙 7가지.

1. **찾아가는 게 아니라 도착해 있어야 한다.** 행원에게는 Wisenet을 뒤지고 Hot Tip을 검색할 시간이 없다 — 고객 앞에서 검색하는 순간 신뢰가 깎인다. 본부 자료의 '위치'를 아는 것 자체가 노하우로 공유되는 현실이 도달 실패의 증거다.
2. **분량은 한 장, 근거는 접어서.** 기본 화면은 요약만 보여주고, 판단 근거·출처는 펼치면 나오게 한다.
3. **문장은 입에 넣을 수 있는 완성형으로.** "수수료 면제 조건을 안내하세요"(지시) ❌ → "고객님, 연금 수령 개시하면 운용·자산관리 수수료 면제됩니다"(대사) ⭕. 원자료(마스터북·이탈방어 스크립트)가 이미 대사체다 — 출력도 같은 문법을 따른다.
4. **수치는 원 단위 금액 + 기준시점.** "약 0.2%쯤"이 아니라 "2026.3월 기준 0.21%". 비율보다 금액("환급 148만원")이 통하고, 틀린 수치는 민원이 된다.
5. **신뢰 표시를 항상 붙인다.** 본부 공식인지 / 현장 팁인지 / 대외 공개 자료라 고객에게 그대로 보여줘도 되는지(⭕/사내)를 모든 재료에 표시한다.
6. **"하지 말 것"이 "할 것"만큼 중요하다.** 금지 용어(고유계정대→현금성자산), 민감 고객 주의, 계좌 상태 제약, 사전 고지. 실수는 곧 민원 — 경고 없는 브리핑은 불안해서 못 쓴다.
7. **완성형으로 만든다 — 1차 수혜자는 신입~중견이다.** 게시판 조회수 1위가 신입 가이드(1,821회)다. "아는 사람용 요약"이 아니라 모르는 사람도 따라갈 수 있게 완성 대사·화면번호·처리 순서까지 담는다.

## ① 영업 전 — "고객 1장 브리핑" (읽는 데 30초)

전화 걸기 전, 또는 고객이 번호표 뽑고 걸어오는 동안 볼 수 있는 딱 한 장.
행내 자료의 "상담 전 준비 체크리스트"(IRP관리방법론 8번)를 **고객별로 자동 완성**해주는 기능이다.

### 필수 구성 요소

1. **이 고객이 왜 대상인가** — "고유대 62% + ISA 만기 38일 전. 이런 고객 이탈률은 일반의 1.3배" ← 행원이 확신을 갖고 전화하게 만드는 근거
2. **계좌 스냅샷** — 적립금, 구성 3층(현금성/원리금/실적배당), 수익률과 기준선 격차, 만기 임박 상품, 최근 접촉 이력
3. **고객이 모르는 자기 현황** — 연간 납입액·공제액·분산 계좌 현황. 이걸 정리해 보여주는 것이 최강의 오프너
4. **오늘의 제안 1개 (+예비 1개)** — 우선순위가 정해져서 옴. 제안 5개 나열은 안 하느니만 못함. 니즈가 복수면 우선순위 판단 근거 병기
5. **예상 반론 2~3개와 답** — 이 고객 프로필에서 나올 법한 것만 (즉답 카드 링크)
6. **⚠ 하지 말 것** — "수익률 저조 고객 → 지적 금지, 개선안으로 접근" / "연금개시 계좌 → 추가납 권유 금지" / 금지 용어
7. **통화 전 확인할 화면 1~2개** — 번호까지: "[04-12-644] 입금 사유 확인 (사용계획 자금이면 오탐)"

### 양식 (초안)

```
┌─ 고객 브리핑 ─ ○○○ 고객님 (만 57세 · VIP) ─────── 2026.08.19
│
│ ■ 왜 지금: 고유계정대 62% (4,100만원) + ISA 만기 D-38
│   → 편중 고객 이탈률 1.3배 (본부 최우선 관리군)     [근거▸]
│
│ ■ 계좌: 적립금 6,600만원 = 현금성 62% | 정기예금 23% | 펀드 15%
│   수익률 1.2% (IRP 평균 7.97% 대비 -6.8%p) · 정기예금 만기 11/20
│   최근 접촉: 없음 (6개월+)
│
│ ■ 고객이 모르는 것: 올해 납입 0원 (작년 600만원) · 잔여 세액공제 한도 900만원
│
│ ■ 오늘의 제안: ① 방치 현금성자산 일부(500만~1천만) 운용 전환
│               (예비: ② ISA 만기자금 60일 내 IRP 전환 — 만기 후 재접촉 예약)
│
│ ■ 예상 반론:
│   "고유계정대도 이자 붙던데요" → [즉답 카드 T-10 ▸]
│   "생각 좀 해볼게요"          → [즉답 카드 T-19 ▸]
│
│ ■ ⚠ 하지 말 것: 수익률 직접 지적 금지 · "고유계정대" 용어 금지("현금성자산")
│ ■ 통화 전 확인: [04-12-644] 입금사유 (교체매매·연금지급이면 오탐 → 접촉 보류)
└──────────────────────────── 근거·출처는 각 [▸]에 접힘
```

### 왜 이렇게 구성했나 (근거)

- **"고객이 모르는 자기 현황" 칸** — "보통 고객들은 본인이 얼마를 납입하고 공제받는지 모르는 경우가 많음. 이를 타겟으로" 「IRP 계약이전 섭외 시 이건 모르셨죠」(서영주). 정보 비대칭 해소가 현장 검증된 최고의 오프너.
- **제안 1개 + 우선순위 근거** — 51억 유치 사례에서 고객 니즈 3개 중 퇴직금을 핵심으로 판단하고 나머지를 먼저 정리해준 것이 성공 요인 「꼼꼼한 고객관리로 거액의 개인형IRP 유치하기」(양혜련). 제안이 많으면 행원도 고객도 길을 잃는다.
- **"왜 지금" 근거 수치** — 이탈률 1.3배, 가중치 △1.65 같은 근거가 있어야 행원이 확신을 갖고 접촉한다 (Series1·「개인형IRP 수탁고 잔액증대」(송현진)). 명분 없는 접촉 리스트는 소화되지 않는다.
- **오탐 제거 확인 칸** — 현금성자산이 보여도 연금지급·교체매매 대기 자금일 수 있다는 판정 기준이 행내 자료에 이미 있다 (KPI시나리오 2021 → 방법론 6번). 오탐 접촉 한 번이 고객 신뢰를 깎는다.
- **하지 말 것 칸** — "제가 낭패를 본 경험이 있어 연금수령 중인 고객은 하지 마세요" 「스타뱅킹을 통한 개인형IRP 이용방법」(강현애) — 현장은 실패담으로 서로를 방어시키고 있다. 이걸 브리핑에 내장한다.
- **맞춤 문서 자동화 자체의 근거** — 고성과 행원의 공통 기술이 고객별 정리표·제안서 제작이고, 가장 시간이 드는 병목이다 (양혜련·김정희·엄주원 사례). 브리핑 자동 생성은 평균 행원에게 고성과 행원의 도구를 주는 것.

## ② 영업 중 — 3초 안에 꺼낼 수 있는 것들

상담 중엔 읽을 시간이 없다. 고객이 "증권사는 수수료 무료라던데요" 하는 순간 3초 안에 답해야 한다.
형태는 문서가 아니라 **묻고 답하는 인터페이스**여야 한다.

### 필수 구성 요소

1. **반론 즉답 카드** — 고객 말 → **그대로 읽어도 되는 완성 문장** + 근거 수치(기준시점 포함)
2. **판별 질문 리스트** — 다음 분기를 타려면 고객에게 뭘 물어야 하는가. "실적배당 희망하세요, 원리금보장 희망하세요?" / "일시금으로 쓰실 계획이세요, 연금으로 받으실 계획이세요?" — **분기 조건이 곧 질문지**
3. **계산기** — 중도해지 유불리, 환급 예상액, 연금수령한도. 결과는 원 단위 금액으로
4. **가능 여부 즉시 확인** — "이 고객에게 지금 이 제안 되나?" 상태 플래그(연금개시·진행 중 거래·AI일임) 조회

### 양식 (초안) — 즉답 카드

```
┌─ T-01 · "증권사는 수수료 무료라던데요" ────────────────
│ [분기 먼저] 만 55세 이상? → A / 퇴직금 5천만원 이상? → B / 그 외 → C
│
│ A▸ "고객님, 연금 수령 개시하면 운용·자산관리 수수료 면제됩니다."
│ B▸ "비대면 계좌로 전환하시면, 퇴직금에 대한 수수료가 면제됩니다."
│ C▸ "2025년 10월부터 대면 계좌를 비대면으로 전환할 수 있게 됐어요.
│     수수료는 매년 신규일에 후취라 지금 전환하시면 다음 납입일부터 인하됩니다."
│
│ + 추가 논거: 가입기간 승계 — 타사→KB는 인정(장기할인), KB→증권사는 소멸
│ ⚠ 사전 고지: 전환 적용은 전환일 다음날 이후 첫 수수료 납입일부터
│ 근거: 보물지도 2026.03 §이탈방어 Step05 [본부공식] · 수수료율표 F50 (2026.3월 기준)
└─ 신뢰도: 본부공식 ✅ · 고객 제시 가능: 표현 변경 후
```

카드 필수 필드: **고객 발화(트리거) / 조건 분기 / 완성 대사 / 추가 논거 / ⚠사전 고지 문구 / 근거+기준시점 / 신뢰 표시**

### 왜 이렇게 구성했나 (근거)

- **완성 대사 + 조건 분기** — 본부 이탈방어 스크립트가 이미 "고객 조건별 표 분기 + 대사체"로 쓰여 있다 (보물지도 Step05 수수료 표). 원자료의 형식이 곧 현장이 원하는 형식.
- **금액 계산기** — 세액공제 미신청금액 계산기를 직원 2명이 각자 엑셀로 만들어 배포했다 「IRP 세액공제 미신청금액 계산기」(김유미), 「정말 쉬운 세액공제 미신청금액 계산기」(장혜영). 도구가 없으면 사비로 만들 만큼 강한 니즈. "계산해주면 전문가다운 모습 뿜뿜, 고객 신뢰도 업업" 「퇴직소득세 계산 어렵지 않아요」(김재).
- **원 단위 금액 원칙** — "중도해지로 못 받는 이자 9천만원이면 고객도 멈칫" 「퇴직연금 Total Marketing 사례」(엄주원), "16.5%+2.8% = 19% 적금" 「무조건 가입하는 개인형IRP 권유꿀팁」(최수인). 비율은 안 통하고 금액이 통한다는 게 반복 검증된 패턴.
- **사전 고지 문구 필수 칸** — "미흡한 설명 시 원금 손실·현금화 지연을 근거로 민원 제기 가능" 「상품별 Pain Point 극복하기」(진승현). 고지는 부가 정보가 아니라 화법과 동급의 재료 — 제안 문장과 고지 문장이 항상 세트로 나가야 한다.
- **가능 여부 즉시 확인** — 계좌 상태(연금개시·진행 중 거래)가 가능한 행동을 결정한다는 것이 행내 자료·현장 경험 공통의 교훈 (방법론 59번, 강현애의 낭패 경험). 설득 후 거래가 튕기는 참사를 상담 중에 막는다.
- **판별 질문 = 분기 조건** — 본부 Mission 스크립트가 "실적배당 희망/원리금보장 희망"을 고객에게 직접 묻는 방식으로 분기한다 (Series1 Mission 1·2). 지식의 분기 조건을 질문지로 뒤집으면 행원이 상담을 끌고 갈 수 있다.

## ③ 영업 후 — 실행 체크리스트 · 진행 추적

합의는 됐는데 처리에서 실수하면 도루묵 — 접수 취소·거절 사례가 Hot Tip에 수두룩하다.

### 필수 구성 요소

1. **화면번호 순서대로** — 함정 경고 포함: "디폴트옵션 상향은 ⓐ등록변경 → ⓑ보유상품변경 **2단계**, 하나만 하면 절반 처리"
2. **필요 서류·발송 링크** — URL 발송 시 "직원명 **수기 입력** 안내"까지 (안 하면 실적 미인정)
3. **함정 경고** — 실물이전 거절 5사유, 타행 비밀번호 미설정, 서류 선징구(제신고서+신분증)
4. **진행 추적** — 신청 후 상태를 에이전트가 감시, 거절 감지 시 사유+재신청 경로 알림
5. **후속 예약 심기** — "6개월 뒤 재점검", "만 55세 되는 ○월 재접촉", 만기예약 — 그 자리에서 다음 접점을 예약

### 양식 (초안)

```
┌─ 실행 체크리스트 · 디폴트옵션 상향 (초저위험→저위험) ──────
│ □ 1. [사전지정운용제도 등록/변경] 등급 변경          ⚠ 여기서 멈추면 절반 처리
│ □ 2. [보유상품 변경] 기존 초저위험 매도 + 신규 매수
│ □ 3. 고객 안내: 2단계임을 미리 고지했는가
│ □ 4. CRM 상담 기록 등록
│ □ 5. 후속 예약: 6개월 뒤 수익률 점검 (2027.02) — 알림 등록됨
│ ▷ 진행 추적: 체결 완료 시 알림 / 실패 시 사유+재처리 경로 안내
└──────────────────────────────────────
```

### 왜 이렇게 구성했나 (근거)

- **함정 경고 필수** — "이전 등록했는데 갑자기 접수 취소되는 경우, 이런 경우는 99%…" 거절 사유 5분류를 현장이 스스로 정리했다 「IRP 이전 접수 취소 해결방법」(오현석). "하나은행 비밀번호 미설정으로 거절 — 이제는 미리 등록해드리고 신청해야" 「하나은행 계좌이전등록전 체크리스트」(김현정). 실행 함정이 가장 아픈 실패담이고, 사후 공유가 아니라 사전 경고로 바꿔야 한다.
- **진행 추적 알림** — 타행 3차 확인전화 무응답으로 거절 통보, "고객은 동의 완료된 줄 알고 계셨다 — 아무리 바쁘더라도 꼭 [06-AD-080]을 수시로 조회" 「신통방통⑨ 개인형IRP 계약이전」(신은지). 지금 행원이 수동으로 하는 감시를 에이전트가 대체 — 자동화 우선순위 1번.
- **2단계 거래 경고** — 디폴트옵션 상향은 등록변경+보유상품변경 2단계이며 하나만 하면 절반 처리라는 주의가 본부 스크립트에 명시돼 있다 (오늘의할일 시트25). 원자료가 경고하는 함정은 체크리스트에 그대로 내장한다.
- **실적 인정 조건 안내** — "URL 상품변경 시 직원명이 자동 입력되지 않아 고객이 수기로 입력해야 실적 인정" 「고객수 단기간 최대득점하기」(박서영). 챙기지 못하면 실적이 증발하는 조건은 체크 항목으로.
- **후속 예약** — "6개월이나 1년에 한 번씩 점검해드리니 고객이 찾아와서 추가 변경을 요청한다" 「퇴직연금운용」(김정남). 재접촉을 그 자리에서 심는 것이 관리 사이클을 돌게 만든다.

### 왜 이렇게 구성했나 (근거)

- **기한 우선 정렬** — 퇴직금·ISA의 60일, 만기 1개월 전 등 기한이 붙은 고객은 지나면 기회가 소멸한다 (보물지도 §추가납·§퇴직금). 타이머가 곧 우선순위라는 것이 행내 자료의 일관된 논리.
- **이달의 수치 한 곳** — 예금 금리는 월 단위 확정이라 월말 매수는 다음 달 금리가 적용되고(「고객수 단기간 최대득점하기」(박서영)), 매월 마지막 영업일의 특별제공상품 게시가 만기 상담의 기반이다(「퇴직연금 Total Marketing 사례」(엄주원)). 갱신 주기를 아는 것이 노하우가 된 현실을 자동화한다.
- **본부 자료 라우팅** — "WiseNet 타겟리스트에 너무 좋은 리스트가 있답니다" 「D-70! WM고객 절세 점검 리스트」(이채희). 자료는 이미 있다, 도달이 문제다 — 대시보드가 도달을 대신한다.
- **실적 인정 표시** — 행원의 시간은 KPI로 배분된다. 점수와 연결 안 되는 리스트는 소화되지 않는다 (「우리지점 퇴직연금 사수하기」(박주영) 등 다수). 단, 고객 이익과 어긋나는 득점 지식의 반영 범위는 팀이 선을 긋는다.
- **관리 현황(사각지대 점검)** — "관리되지 않은 퇴직연금의 이탈은 막을 수 없다" 「퇴직연금 Total Marketing 사례」(엄주원). 이탈은 관리 소홀의 결과라는 인과가 행내 자료·현장 경험 공통의 결론 — 미접촉·방치 계좌를 보이게 만드는 것이 이탈방어의 시작.
