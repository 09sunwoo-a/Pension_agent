# 퇴직연금 지식베이스 (Pension Agent)

KB국민은행 퇴직연금·개인형IRP 관련 자료를 마크다운으로 변환·정리한 지식베이스입니다.
행내 배포자료, 스타런(사내 학습 포털) 교육자료·게시글, KB Think 공개 콘텐츠를 모았습니다. (수집: 2026.08)

| `02_스타런_퇴직연금_교육자료` | 스타런 교육 동영상(STT 전사)·연수 PDF | 15 문서 + 원본 17 | 이탈방지 상담, 투자교육, 마케팅 전략 |

- `01`~`03` 폴더는 행내·사내 포털 자료 기반입니다. 일부 문서에 대외비 표기가 있으므로 **저장소는 Private 유지**를 전제로 합니다.
- `04_KBthink_연금`만 공개 웹 콘텐츠 기반입니다.
- 날짜·원본 파일명은 각 문서에 명시된 것만 표기했으며, 명시가 없는 항목은 비워두었습니다.
