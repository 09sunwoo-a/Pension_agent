# 연금 에이전트

KB국민은행 영업점 직원이 퇴직연금(IRP) 고객을 상담할 때 쓰는 대화형 에이전트와, 그 에이전트가
근거로 쓰는 퇴직연금·개인형IRP 지식베이스를 담은 저장소다.

- **에이전트를 설치·실행·배포하려면** → [src/README.md](src/README.md). 행내에는 `src/` 폴더만
  옮기므로 그 문서 하나로 완결된다.
- **프론트·게이트웨이에서 에이전트를 부르려면** → [client/README.md](client/README.md)
- **작업 규칙** → [CLAUDE.md](CLAUDE.md)
