## 1. 문서 개요

### 1.1 문서 목적

영업점 직원이 특정 고객의 개인형IRP를 조회했을 때, 에이전트가 고객·시장·운용 데이터를 종합 분석하여 "왜 지금 이 고객을 관리해야 하는지 → 어떤 솔루션을 검토할지 → 고객에게 어떻게 말할지 → 상담에 활용할 자료와 후속 접점을 무엇으로 활용할지"를 한 화면에서 제공하기 위한 상세 요건을 정의한다.

### 1.2 화면명

퇴직연금 사후관리 에이전트

### 1.3 핵심 UX 원칙

- 세로 스크롤 기반의 단일 콘텐츠 화면으로 구성한다.
- 탭으로 분산하지 않고 고객 상담에 필요한 내용을 순차적으로 제공한다.
- 직원이 위에서 아래로 읽으면 상담 준비가 자연스럽게 완료되는 구조로 설계한다.
- 데이터 나열보다 AI가 해석한 문장 중심으로 구성한다.
- 각 섹션의 역할을 명확히 분리하여 동일한 솔루션 문장이 반복되지 않도록 한다.
- 숫자·차트는 시스템 산출값을 사용하고 LLM이 임의 생성하지 않는다.
- LLM은 정형 데이터를 종합·해석·추천·문장화하는 역할을 담당한다.
- 실제 금융거래 실행은 직원의 판단 및 기존 거래 프로세스를 거친다.

## 2. 화면 전체 구조

상단에는 고객 프로파일을 배치하고, 하단에는 ① AI 브리핑부터 ⑨ 고객님께 안내해보세요까지 상담 준비의 흐름에 맞춰 세로 스크롤로 구성한다.

| 위치 | 섹션 | 역할 |
|---|---|---|
| 상단 고정 | 고객 프로파일 / 핵심 IRP 정보 / 상태 Badge | 대상 고객과 핵심 상태 즉시 파악 |
| ① | AI 브리핑 | 모든 요소를 종합한 최상위 상담 전략 |
| ② | 왜 이 고객님인가요? | 전략을 뒷받침하는 핵심 근거 3개 |
| ③ | 현재 운용상태 | 포트폴리오·성과 현황과 국소적 AI 코칭 |
| ④ | 수익률 상위 1% 고객님들이 많이 담은 상품은? | 고성과 고객 운용 사례 |
| ⑤ | 이런 상품이 적합할 수 있어요 | LLM이 선별한 상품 1개 + 포트폴리오 1개 |
| ⑥ | 이렇게 말해보세요 | 고객에게 직접 전달할 TM 화법 2개 |
| ⑦ | 예상 반론 및 대응 화법 | 고객별 예상 반론 2개 |
| ⑧ | 상담에 참고하세요 | 당행 문서·가이드·노하우 리소스 2개 |
| ⑨ | 고객님께 안내해보세요 | 가장 임박한 이벤트 1개 + 세미나 1개 |

## 3. 상단 고객 프로파일 영역

화면 진입 즉시 대상 고객과 핵심 IRP 상태를 파악할 수 있도록 구성한다. 스크롤 시 상단 고정 형태를 우선 검토한다.

### 3.1 고객 기본정보

| 항목 | 예시 | 요건 |
|---|---|---|
| 고객명 | 김자산 고객님 | 가장 큰 텍스트로 강조 |
| KB-PIN | 105636-2876753 | 직원 식별용. 보안정책에 따라 마스킹 가능 |
| 생년월일 | 1983.07.12 | 고객 기본정보 |
| 나이 | 41세 | 고객 기본정보 |
| 성별 | 남 | 고객 기본정보 |
| 스타클럽등급 | VIP | 고객 등급 표시 |
| 투자성향 | 적극투자형 | 현재 등록된 투자성향 |
| 최근 접촉일 | 2025.05.12 | 최근 상담/접촉일 |

> ※ 화면 자체가 개인형IRP 사후관리 화면이므로 '개인형IRP' 별도 Badge는 표시하지 않는다.

### 3.2 IRP 핵심정보 카드

| 카드 | 표시 예시 | 주요 요건 |
|---|---|---|
| 신규가입일 | 2019.03.25 | 가입일 및 필요 시 가입 경과기간 표시 |
| 평가금액 | 42,680,000원 | 기존 '적립금' 명칭을 전면적으로 '평가금액'으로 통일 |
| 디폴트옵션 | 설정됨 | 설정/미설정. 설정 시 유형/위험도 표시 가능 |
| 세액공제 잔여한도 | 3,600,000원 (40%) | 총 한도 900만원 기준 Progress Bar 시각화 |

### 3.3 세액공제 잔여한도 Progress Bar

총 세액공제 한도 9,000,000원을 기준으로 사용금액과 잔여금액을 시각화한다. 잔여비율은 시스템에서 '잔여한도 ÷ 총 한도 × 100'으로 산출하며 LLM이 계산하지 않는다.

### 3.4 AI 분석 상태 Badge

- 예금 편중
- 성향·보유 불일치
- 장기 운용방치 우려

Badge는 고객상태 레짐/Rule에서 도출하며, 긴 설명 대신 핵심 상태만 짧게 표시한다.

## 4. ① AI 브리핑

화면 전체의 최상위 종합 판단을 제공한다. ③ AI 코칭이나 ⑤ 상품추천처럼 특정 요소만 설명하는 영역이 아니라 고객의 자산규모·운용상태·상대성과·투자성향·시장환경·세액공제·운용기간 등을 종합해 가장 중요한 상담 방향을 제안한다.

### 4.1 문장 구조

**현재 상태 → 주요 근거 → 종합 솔루션 → 직원에게 제안**

> 예시: "김자산 고객님은 평가금액은 높은 수준이지만 수익률은 상대적으로 낮고, 적극투자형 성향에 비해 원리금보장형 비중이 높은 상태입니다. 자산 규모에 맞는 운용 효율을 높일 수 있도록 실적배당형 비중 확대와 글로벌 분산 운용을 중심으로 상담을 제안해보세요."

- 고객에게 직접 말하는 화법이 아니라 영업점 직원에게 제안하는 **코칭 문체**를 사용한다.
- 마무리는 '~제안해보세요', '~점검해보세요' 등으로 구성한다.
- 기존 시안 대비 글자 수를 약 50% 수준으로 축소한다.
- 2~3문장 이내를 원칙으로 하며 가독성을 우선한다.

## 5. ② 왜 이 고객님인가요?

AI 브리핑의 판단을 뒷받침하는 핵심 근거 3개를 정량 중심으로 제공한다.

| 근거 | 예시 |
|---|---|
| 평가금액 | 평가금액 4,268만원으로 유사 고객 상위 9% 수준이에요. |
| 수익률 | 최근 1년 수익률은 -2.35%로 유사 고객 하위 18% 수준이에요. |
| 운용구조 | 적극투자형 성향 대비 원리금보장형 비중이 60%로 높아요. |

- 최대 3개
- 각 근거는 1줄 중심
- 정량 데이터 우선
- AI 브리핑의 근거를 반복하되 동일 문장을 복제하지 않는다.

## 6. ③ 현재 운용상태

고객의 실제 IRP 포트폴리오와 성과를 보여주고, 이를 기반으로 국소적인 AI 코칭을 제공한다.

### 6.1 AI 코칭 제안 카드

현재 운용상태 영역에서는 'AI 코칭 제안'만 클릭 가능한 카드로 구성한다. 시안은 카드가 클릭되어 상세정보가 펼쳐진 상태로 설계한다.

> 예시: "평가금액은 상위권이지만 수익률은 낮고, 원리금보장형 비중이 높아 운용 효율이 제한된 상태입니다. 적극투자형 성향을 고려해 실적배당형 비중을 확대하고 글로벌 분산 운용을 점검해보세요."

- 2문장 이내
- '실적배당형 40~60% 확대'와 같은 구체적인 목표비중은 표현하지 않고 '비중을 확대' 정도로 표현한다.
- 텍스트는 가로 폭을 최대한 활용하여 영역의 세로 길이를 줄인다.

### 6.2 클릭 시 펼쳐지는 상세정보

포트폴리오 구성과 성과 요약을 하단에 표출한다.

| 구분 | 예시 비중 | 예시 평가금액 |
|---|---|---|
| 고유계정대 | 10% | 4,268,000원 |
| 실적배당형 | 30% | 12,690,000원 |
| 원리금보장형 | 60% | 25,710,000원 |

포트폴리오 구성은 파이차트로 ① 고유계정대 ② 실적배당형 ③ 원리금보장형 3개 영역으로 시각화한다. 고유계정대는 현실성 있는 일부 비중을 남긴다.

### 6.3 성과 요약

| 지표 | 예시 | 표현 |
|---|---|---|
| 수익률 백분위 | 하위 18% | 유사 고객 기준 |
| 평가금액 백분위 | 상위 9% | 유사 고객 기준 |

'동일 유형 고객 기준'이라는 문구는 사용하지 않고 **'유사 고객 기준'**으로 통일한다.

## 7. ④ 수익률 상위 1% 고객님들이 많이 담은 상품은?

고성과 고객의 실제 운용 사례를 비교·참고 정보로 제공한다. 해당 영역 자체가 고객 적합상품 추천을 의미하지 않도록 구분한다.

| 상품명 | 한줄 설명 | 최근 1년 수익률 |
|---|---|---|
| 트러스톤적격TDF2050증권자투자신탁(혼합-재간접형)CP2-E | 2050년 은퇴를 목표로 자산배분을 자동 조정하는 장기 투자형 TDF 펀드 | 예: 18.75% |
| 삼성 EMP 리얼리턴 (UH) (주식혼합-재간접) | 주식·채권·대체자산에 분산 투자하여 장기 수익을 추구 | 예: 14.32% |

> 삭제 항목: 상위 1% 고객 보유 비중 등 보유비중 수치.

## 8. ⑤ 이런 상품이 적합할 수 있어요

월간 퇴직연금 펀드 가이드와 당행 상품/시장 자료를 학습한 LLM이 시장상황·고객상태·상품특성을 종합하여 현재 고객에게 적합한 솔루션을 선별한다.

**핵심 요건:** 모든 선택지를 나열하지 않고 LLM이 ① 상품 1개 ② 포트폴리오 1개를 선정한다.

### 8.1 추천 상품

표시 구조: **상품명 → 한줄 설명 → 최근 1년 수익률 → AI 추천 사유**

> 예시: 마이다스 아시아 리더스 성장주(H)(주식) / 성장 잠재력이 높은 아시아 지역 주식에 투자 / 최근 1년 47.19%

AI 추천 사유 예시:

- **시황**: 아시아 주요국 성장 모멘텀 지속
- **고객 상태**: 적극투자형으로 장기 투자 가능
- **상품 특성**: 성장성 및 글로벌 분산 효과

### 8.2 추천 포트폴리오

| 상품 | 유형 | 비중 | 최근 1년 수익률 |
|---|---|---|---|
| 교보악사 투마로우 장기우량K-1 | 채권 | 40% | 예: 3.21% |
| NH-AmundiUSD 초단기채권(UH) | 채권 | 30% | 예: 4.18% |
| 한국투자웰링턴 글로벌퀄리티(H) | 주식 | 30% | 예: 16.87% |

- 교보악사 투마로우 장기우량K-1: 안정성 높은 채권 투자로 안정적 이자 수익 추구
- NH-AmundiUSD 초단기채권(UH): 미달러 표시 초단기채권에 주로 투자
- 한국투자웰링턴 글로벌퀄리티(H): 전 세계 기업들이 발행하는 주식 및 DR에 주로 투자

### 8.3 종합 AI 추천 사유

> 예시: "성장성은 유지하면서 채권 비중을 높여 변동성을 낮출 수 있어요."

LLM이 직접 생성·해석한 문장임을 UI에서 시각적으로 강조한다.

## 9. 상품추천 LLM 입력 데이터

| 구분 | 입력 정보 |
|---|---|

## 17. 데이터 처리 및 검증 원칙

- 평가금액·수익률·백분위·포트폴리오 비중·세액공제 금액 등 정량값은 LLM이 생성하지 않는다.
- LLM은 시스템에서 제공한 값을 해석하고 문장화한다.
- 상품 추천은 당행 상품 DB 및 월간 퇴직연금 펀드 가이드 범위 내에서만 수행한다.
- 추천 결과에는 최소한 시황·고객 상태·상품 특성의 근거가 존재해야 한다.
- 고객에게 직접 제시하는 화법과 직원에게 제시하는 코칭 문체를 구분한다.
- AI 브리핑은 종합 전략, AI 코칭은 국소적 운용 진단으로 역할을 구분하여 중복을 방지한다.
- 상담 참고자료는 당행 내부 문서를 검색·선별하는 RAG/지식검색 기능과 연계한다.
- 이벤트·세미나는 콘텐츠 DB의 일정 정보를 기준으로 종료 콘텐츠를 제외한다.

## 18. 전체 화면의 업무 흐름

```
고객 분석 → 상담 전략 → 근거 확인 → 운용상태 점검 → 비교사례 확인
   → 맞춤 솔루션 → 고객 화법 → 반론 대응 → 상담 참고자료
   → 고객 안내 콘텐츠 → 상담 이력 등록
```

이 화면은 단순 'AI 고객분석 화면'이 아니라, 고객별 사후관리 상담을 실제로 준비하고 실행할 수 있도록 지원하는 **AI 기반 업무지원 화면**으로 정의한다.

---

## 19. 향후 Agentic 확장 방향

현재 화면은 에이전트의 '판단 및 상담 준비' 단계에 해당한다. 향후 상담 이력 등록을 기점으로 상담 결과를 다시 고객상태 데이터에 반영하고, 다음 관리대상 및 Action을 생성하는 폐쇄형 업무 루프까지 확장한다.

```
AI 분석 → 상담 준비 → 상담 이력 등록 → 상담 결과 반영
   → 고객 상태 재평가 → 다음 관리 Action 생성
```
