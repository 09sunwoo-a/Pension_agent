# 에이전트 출력 스펙 — 행원 참고자료 4종 (상담의 시간축 기준)

> 작성 2026-08-19 · 근거: AS-IS 문서 전수 + Hot Tip 50건 전수 분석(`현장의목소리_HotTip_50건_분석.md`)
> **목적**: 에이전트가 행원에게 무엇을·언제·어떤 형태로 제공하는지의 출력 표준.
> 살 붙이기(노드별 지식 꾸러미 제작) 시 **"이 재료가 최종적으로 어느 양식의 어느 칸에 들어가는가"** 의 기준 문서.

핵심 관점: **"무엇을"보다 "언제, 어떤 형태로"**. 상담의 시간축(전·중·후·평상시)에 따라 필요한 것이 전혀 다르며, 각 시점의 산출물은 코어로직 뼈대의 트랙과 1:1 대응한다.

|---|---|---|---|
| ① 상담 전 | 고객 1장 브리핑 | 사전 브리핑 모드 (E1~E3 → P0~P3) | 정적 문서 (30초 독해) |
| ② 상담 중 | 즉답 카드·판별 질문·계산기 | 상담 지원 모드 (E4, D3, P2~P4) | 묻고 답하는 인터페이스 (3초 응답) |
| ③ 상담 직후 | 실행 체크리스트 | P5·D5 | 순서형 체크리스트 |
| ④ 평상시 | 접촉 리스트·갱신 수치·관리 현황 | 상시 사이클 | 대시보드 |

## ① 상담 전 — "고객 1장 브리핑" (읽는 데 30초)

전화 걸기 전, 또는 고객이 번호표 뽑고 걸어오는 동안 볼 수 있는 딱 한 장.
방법론 8번 "상담 전 준비 체크리스트"를 **고객별로 자동 완성**해주는 것 = 사전 브리핑 모드의 출력 그 자체.

### 필수 구성 요소

1. **이 고객이 왜 대상인가** — "고유대 62% + ISA 만기 38일 전. 이런 고객 이탈률은 일반의 1.3배" ← 행원이 확신을 갖고 전화하게 만드는 근거
2. **계좌 스냅샷** — 적립금, 구성 3층(현금성/원리금/실적배당), 수익률과 기준선 격차, 만기 임박 상품, 최근 접촉 이력
3. **고객이 모르는 자기 현황** *(Hot Tip 보강)* — 연간 납입액·공제액·분산 계좌 현황. "고객은 본인이 얼마 납입하고 공제받는지 모른다"(199124) → 이걸 정리해 보여주는 것이 최강의 오프너
4. **오늘의 제안 1개 (+예비 1개)** — 우선순위가 정해져서 옴. 제안 5개 나열은 안 하느니만 못함. 니즈가 복수면 우선순위 판단 근거 병기 (200352 패턴: 니즈 3개 중 퇴직금이 핵심)
5. **예상 반론 2~3개와 답** — 이 고객 프로필에서 나올 법한 것만
6. **⚠ 하지 말 것** — "수익률 저조 고객 → 지적 금지, 개선안으로 접근" / "연금개시 계좌 → 추가납 권유 금지" / 금지 용어
7. **통화 전 확인할 화면 1~2개** — 번호까지: "[04-12-644] 입금 사유 확인 (사용계획 자금이면 오탐)"

### 양식 (초안)

```
┌─ 고객 브리핑 ─ ○○○ 고객님 (만 57세 · VIP) ─────── 2026.08.19
│
│ ■ 왜 지금: 고유계정대 62% (4,100만원) + ISA 만기 D-38
│   → 편중 고객 이탈률 1.3배 (본부 최우선 관리군)     [근거▸]
│
│ ■ 계좌: 적립금 6,600만원 = 현금성 62% | 정기예금 23% | 펀드 15%
│   수익률 1.2% (IRP 평균 7.97% 대비 -6.8%p) · 정기예금 만기 11/20
│   최근 접촉: 없음 (6개월+)
│
│ ■ 고객이 모르는 것: 올해 납입 0원 (작년 600만원) · 잔여 세액공제 한도 900만원
│
│ ■ 오늘의 제안: ① 방치 현금성자산 일부(500만~1천만) 운용 전환
│               (예비: ② ISA 만기자금 60일 내 IRP 전환 — 만기 후 재접촉 예약)
│
│ ■ 예상 반론:
│   "고유계정대도 이자 붙던데요" → [즉답 카드 T-10 ▸]
│   "생각 좀 해볼게요"          → [즉답 카드 T-19 ▸]
│
│ ■ ⚠ 하지 말 것: 수익률 직접 지적 금지 · "고유계정대" 용어 금지("현금성자산")
│ ■ 통화 전 확인: [04-12-644] 입금사유 (교체매매·연금지급이면 오탐 → 접촉 보류)
└──────────────────────────── 근거·출처는 각 [▸]에 접힘
```

## ② 상담 중 — 3초 안에 꺼낼 수 있는 것들

상담 중엔 읽을 시간이 없다. 고객이 "증권사는 수수료 무료라던데요" 하는 순간 3초 안에 답해야 한다.
형태는 문서가 아니라 **묻고 답하는 인터페이스** = 상담 지원 모드.

### 구성 요소 4종

1. **반론 즉답 카드** — 고객 말 → **그대로 읽어도 되는 완성 문장** + 근거 수치(기준시점 포함). "약 0.2%쯤"이 아니라 "2026.3월 기준 ○○%". 틀린 수치는 민원이 된다 — 수치의 신선도가 생명
2. **판별 질문 리스트** — 다음 분기를 타려면 고객에게 뭘 물어야 하는가. "실적배당 희망하세요, 원리금보장 희망하세요?" / "일시금으로 쓰실 계획이세요, 연금으로 받으실 계획이세요?" — **분기 조건이 곧 질문지**
3. **계산기** — 원칙: **비율이 아니라 원 단위 금액으로** ("못 받는 이자 9천만원", "19% 적금"). 중도해지 유불리, 환급 예상액, 연금수령한도. 직원들이 계산기를 사비로 만들어 공유한 것(199713·200518)이 이 니즈의 증거
4. **가능 여부 즉시 확인** — "이 고객에게 지금 이 제안 되나?" 상태 플래그(연금개시·진행 중 거래·AI일임)를 상담 중에 조회 — 다 설득해놓고 거래가 튕기는 참사 방지

### 즉답 카드 양식 (초안)

```
┌─ T-01 · "증권사는 수수료 무료라던데요" ────────────────
│ [분기 먼저] 만 55세 이상? → A / 퇴직금 5천만원 이상? → B / 그 외 → C
│
│ A▸ "고객님, 연금 수령 개시하면 운용·자산관리 수수료 면제됩니다."
│ B▸ "비대면 계좌로 전환하시면, 퇴직금에 대한 수수료가 면제됩니다."
│ C▸ "2025년 10월부터 대면 계좌를 비대면으로 전환할 수 있게 됐어요.
│     수수료는 매년 신규일에 후취라 지금 전환하시면 다음 납입일부터 인하됩니다."
│
│ + 추가 논거: 가입기간 승계 — 타사→KB는 인정(장기할인), KB→증권사는 소멸
│ ⚠ 사전 고지: 전환 적용은 전환일 다음날 이후 첫 수수료 납입일부터
│ 근거: 보물지도 2026.03 §이탈방어 Step05 [본부공식] · 수수료율표 F50 (2026.3월 기준)
└─ 신뢰도: 본부공식 ✅ · 고객 제시 가능: 표현 변경 후
```

카드 필수 필드: **고객 발화(트리거) / 조건 분기 / 완성 대사 / 추가 논거 / ⚠사전 고지 문구(민원 예방) / 근거+기준시점 / 신뢰 표시**

*(Hot Tip 보강)* **사전 고지 문구 칸은 필수** — "미리 안내 안 하면 원금 손실·지연을 근거로 민원 제기 가능"(199167). 고지는 화법과 동급의 재료다.

## ③ 상담 직후 — 실행 체크리스트

합의는 됐는데 처리에서 실수하면 도루묵 (접수 취소·거절 사례가 Hot Tip에 수두룩).

### 구성 요소

1. **화면번호 순서대로** — 함정 경고 포함: "디폴트옵션 상향은 ⓐ등록변경 → ⓑ보유상품변경 **2단계**, 하나만 하면 절반 처리"
2. **필요 서류·발송 링크** — URL 발송 시 "직원명 **수기 입력** 안내"까지 (안 하면 실적 미인정)
3. **함정 경고** *(Hot Tip 보강)* — 실물이전 거절 5사유(상품변경 진행 중/현금성만 보유/불가 ETF/환매불가상품/퇴직금 일부 미입금), 타행 비밀번호 미설정, 서류 선징구(제신고서+신분증)
4. **진행 추적** *(Hot Tip 보강)* — 신청 후 상태를 에이전트가 감시, 거절 감지 시 사유+재신청 경로 알림. (현재 행원이 [06-AD-080]을 수동 "수시 조회" 중 — 자동화 1순위)
5. **후속 예약 심기** — "6개월 뒤 재점검", "만 55세 되는 ○월 재접촉", 만기예약 — 그 자리에서 다음 바퀴를 예약

### 양식 (초안)

```
┌─ 실행 체크리스트 · 디폴트옵션 상향 (초저위험→저위험) ──────
│ □ 1. [사전지정운용제도 등록/변경] 등급 변경          ⚠ 여기서 멈추면 절반 처리
│ □ 2. [보유상품 변경] 기존 초저위험 매도 + 신규 매수
│ □ 3. 고객 안내: 2단계임을 미리 고지했는가
│ □ 4. CRM 상담 기록 등록
│ □ 5. 후속 예약: 6개월 뒤 수익률 점검 (2027.02) — 알림 등록됨
│ ▷ 진행 추적: 체결 완료 시 알림 / 실패 시 사유+재처리 경로 안내
└──────────────────────────────────────
```

## ④ 평상시 — 나를 움직이게 하는 것

1. **오늘의 접촉 리스트** — 누구에게, 왜, **기한이 언제까지인지(60일 타이머 잔여 일수!)** 우선순위 정렬. 이벤트·기한 > 조회형
2. **이달의 갱신 수치** — 특별제공상품 금리, 잔여한도, 추천펀드 — 매월 바뀌는 것들의 최신판 한 곳 (매월 마지막 영업일 게시물 자동 라우팅: "이달 특별제공상품 떴습니다")
3. **내 관리 현황** — 내 담당 중 만기 임박·미접촉·방치 계좌
4. **실적 인정 조건 표시** *(Hot Tip 보강, ⚠팀 결정 범위 내)* — 인정 요건·인정점 귀속을 함께 표시. 실적과 연결되지 않는 도구는 현장에서 쓰이지 않는다

## 형태에 대한 원칙 5가지

1. **찾아가는 게 아니라 도착해 있어야 한다.** Wisenet 뒤지고 Hot Tip 검색할 시간이 없다. 고객 앞에서 검색하는 순간 신뢰가 깎인다. (본부 자료의 '위치'가 노하우가 돼버린 현실 자체가 도달 실패의 증거)
2. **분량은 한 장, 근거는 접어서.** 판단 근거·출처는 펼치면 나오되, 기본 화면은 요약만.
3. **문장은 입에 넣을 수 있는 완성형으로.** "수수료 면제 조건을 안내하세요"(지시) ❌ → "고객님, 연금 수령 개시하면 운용·자산관리 수수료 면제됩니다"(대사) ⭕. 원자료가 이미 대사체다 — 출력도 같은 문법을 따른다.
4. **신뢰 표시.** 본부 공식인지 / 현장 팁인지 / 대외 공개 자료라 고객에게 그대로 보여줘도 되는지(⭕/사내)를 항상 표시.
5. **"하지 말 것"이 "할 것"만큼 중요.** 금지 용어(고유계정대→현금성자산), 민감 고객 주의, 상태 제약, 사전 고지. 실수는 곧 민원 — 경고가 없는 브리핑은 불안해서 못 쓴다.

추가 원칙 *(Hot Tip 보강)*:

6. **화면번호·출처 병기는 현장의 문법이다.** 게시글마다 [04-12-XXX]와 "출처: 문서번호"를 다는 관행 — 같은 문법을 따라야 채택 장벽이 낮다.
7. **1차 수혜자는 신입~중견이다.** 조회수 1위가 신입 가이드(1,821회). "아는 사람용 요약"이 아니라 모르는 사람도 따라갈 수 있는 완성형으로.
